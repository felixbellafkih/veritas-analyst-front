Logic function: ASSEMBLY_CYCLE_SEPARATION // BARREN_STATE

Letter equation: J (Assembly) + R (Cycle) + Z (Separation) = Assembly whose cycle is separated from production.

Description

Sterile state. The assembly (J) cycles (R) a separation (Z) — the cycle separates the assembly from its productive capacity.
