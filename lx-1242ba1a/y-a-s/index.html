Racine Y-A-S (ي أ س) — Lexique Veritas (Maqasid al-Huruf)

ي أ س

Fonction logique : TERMINAL_STATE // HOPE_DEPLETION

Équation des lettres : Y (Action_Active) + A (Instanciation) + S (Flux) = Action active dont l'instanciation du flux atteint un état de stagnation.

Description

État terminal de déplétion. L'action active (Y) d'une instanciation (A) de flux (S) atteint un blocage total.

Paire binaire : R-J-W
