Racine Q-D-H. (ق د ح) — Lexique Veritas (Maqasid al-Huruf)

ق د ح

Fonction logique : PRESSURE_VECTOR_FRICTION // FRICTION_SPARK

Équation des lettres : Q (Pression) + D (Vecteur_Fixe) + H. (Friction) = Pression vectorisée produisant une friction d'étincelle.

Description

Étincelle par friction. La pression (Q) vectorise (D) la friction (H.) — impact pressurisé produisant une friction génératrice d'étincelle.
