Racine D-R-A (د ر ا) — Lexique Veritas (Maqasid al-Huruf)

د ر ا

Fonction logique : VECTOR_CYCLE_INSTANCE // DIRECTIONAL_PUSH

Équation des lettres : D (Vecteur_Fixe) + R (Cycle) + A (Instanciation) = Vecteur fixe cycliquement instancié — poussée directionnelle répétée.

Description

Instanciation d'un cycle vectoriel fixe. Le vecteur fixe (D) cycle (R) une instanciation (A) — projection directionnelle d'une force dans un axe fixe et répété. Couvre tout acte de pousser, repousser ou dévier un élément dans une direction constante.
