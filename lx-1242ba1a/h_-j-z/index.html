ح ج ز

Fonction logique : FIREWALL_PARTITION // QUARANTINE_ZONE

Équation des lettres : H. (Enceinte) + J (Assemblage) + Z (Séparation) = Un assemblage d'enceinte séparant physiquement et logiquement deux flux (FIREWALL_PARTITION).

Description

Confinement d'un processus dans un environnement restreint ou barrière séparatrice (Hajiz).
