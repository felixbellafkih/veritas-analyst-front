Racine L-A-L-A (ل أ ل أ) — Lexique Veritas (Maqasid al-Huruf)

ل أ ل أ

Fonction logique : ALLOC_INSTANCE_ALLOC_INSTANCE // DOUBLE_INSTANTIATED_ALLOCATION

Équation des lettres : L (Allocation) + A (Instanciation) + L (Allocation) + A (Instanciation) = Double allocation instanciée.

Description

Allocation instanciée redoublée. L'allocation (L) instancie (A), puis l'allocation (L) instancie (A) à nouveau — allocation instanciée en double.
