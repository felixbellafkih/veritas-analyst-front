Racine A.-Y-Y (ع ي ي) — Lexique Veritas (Maqasid al-Huruf)

ع ي ي

Fonction logique : DEEP_ACTIVE_ACTIVE // DOUBLE_ACTIVATED_DEEP

Équation des lettres : A. (Connexion_Profonde) + Y (Action_Active) + Y (Action_Active) = Connexion profonde soumise à une double action active.

Description

Connexion profonde en double action active. La connexion profonde (A.) active (Y) une action qui se redouble (Y) — connexion sollicitée par une action répétée.
