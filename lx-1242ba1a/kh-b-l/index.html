Racine KH-B-L (خ ب ل) — Lexique Veritas (Maqasid al-Huruf)

خ ب ل

Fonction logique : EXTRACTION_BASE_ALLOCATION // LOGIC_CORRUPTION

Équation des lettres : KH (Extraction) + B (Base) + L (Allocation) = Déséquilibre d'une allocation par extraction de sa base.

Description

Extraction de la base d'une allocation provoquant une instabilité ou une confusion dans le traitement.
