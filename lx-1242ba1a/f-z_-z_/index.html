Racine F-Z.-Z. (ف ظ ظ) — Lexique Veritas (Maqasid al-Huruf)

ف ظ ظ

Fonction logique : OPEN_SHADOW_SHADOW // SHADOWED_OPENING

Équation des lettres : F (Ouverture) + Z. (Ombre/Masse) + Z. (Ombre/Masse) = Ouverture soumise à une ombre/masse redoublée.

Description

Ouverture sous double ombre/masse. L'ouverture (F) est couverte d'une ombre/masse (Z.) redoublée (Z.) — ouverture alourdie par une masse doublée.
