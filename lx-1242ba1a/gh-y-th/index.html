Racine GH-Y-TH (غ ي ث) — Lexique Veritas (Maqasid al-Huruf)

غ ي ث

Fonction logique : OPAQUE_ACTIVE_DENSITY // ACTIVATED_OPAQUE_DENSITY

Équation des lettres : GH (Opacité) + Y (Action_Active) + TH (Densité) = Opacité activant une densité.

Description

Opacité activée en densité. L'opacité (GH) active (Y) une densité (TH) — couverture opaque qui se densifie.
