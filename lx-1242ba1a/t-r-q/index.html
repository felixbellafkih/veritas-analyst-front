Racine T-R-Q (ت ر ق) — Lexique Veritas (Maqasid al-Huruf)

ت ر ق

Fonction logique : WAY_CYCLE_PRESSURE // PRESSURED_WAY_CYCLE

Équation des lettres : T (Voie) + R (Cycle) + Q (Pression) = Voie cyclique soumise à une pression.

Description

Voie cyclique sous pression. La voie (T) entre en cycle (R) sous pression (Q) — voie cyclique soumise à une pression.
