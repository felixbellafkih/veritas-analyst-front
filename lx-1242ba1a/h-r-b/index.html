Racine H-R-B (ه ر ب) — Lexique Veritas (Maqasid al-Huruf)

ه ر ب

Fonction logique : PROCESS_EVASION // RUNAWAY_THREAD

Équation des lettres : H (Énergie) + R (Cycle) + B (Base) = L'énergie du cycle s'extrayant et fuyant vers la base.

Description

Action d'un processus fuyant sa base d'exécution ou évitant une routine de capture (Fuite/Évasion).

Paire binaire : T.-L-B
