Racine GH-S-L (غ س ل) — Lexique Veritas (Maqasid al-Huruf)

غ س ل

Fonction logique : FLUX_OPACITY_PURGE // MEMORY_WASH

Équation des lettres : GH (Opacité) + S (Flux) + L (Allocation) = Allocation d'un flux dissipant l'opacité.

Description

Allocation d'un flux visant à extraire l'opacité ou les scories de la base matérielle (Lavage).
