Racine Y-A.-Q-W-B (ي ع ق و ب) — Lexique Veritas (Maqasid al-Huruf)

ي ع ق و ب

Fonction logique : ACTIVE_DEEP_PRESSURE_LINK_BASE // DEEP_PRESSURE_ACTIVE_BASE

Équation des lettres : Y (Action_Active) + A. (Connexion_Profonde) + Q (Pression) + W (Lien) + B (Base)

Description

Nom propre coranique (يعقوب). Y (Action_Active) + A. (Connexion_Profonde) + Q (Pression) + W (Lien) + B (Base) = Action active en connexion profonde sous pression liée à la base.

Présente dans 16 verset(s) du Coran

2:132, 2:133, 2:136, 2:140, 3:84, 4:163, 6:84, 11:71, 12:6, 12:38, 12:68, 19:6, 19:49, 21:72, 29:27, 38:45
