Racine KH-T-N (خ ت ن) — Lexique Veritas (Maqasid al-Huruf)

خ ت ن

Fonction logique : EXTRACTION_WAY_MANIFESTATION // INTERFACE_TRIMMING

Équation des lettres : KH (Extraction) + T (Voie) + N (Manifestation) = Manifestation d'une extraction sur la voie.

Description

Extraction d'une voie de manifestation en surface pour ajuster ou protéger un port d'entrée (Circoncision/Taille).
