Racine GH-L-Z. (غ ل ظ) — Lexique Veritas (Maqasid al-Huruf)

غ ل ظ

Fonction logique : HIGH_DENSITY // RIGID_STRUCTURE

Équation des lettres : GH (Couverture) + L (Allocation/Direction) + Z. (Masse_Lourde/Poids) = Couverture directionnelle par poids massique.

Description

Structure à haute densité. Désigne la rigidité, l'épaisseur ou la dureté d'un matériau ou d'un comportement.

Paire binaire : R-Q-Q
