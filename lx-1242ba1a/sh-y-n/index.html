Racine SH-Y-N (ش ي ن) — Lexique Veritas (Maqasid al-Huruf)

ش ي ن

Fonction logique : UI_GLITCH // INTERFACE_DEGRADATION

Équation des lettres : SH (Dispersion) + Y (Action_Active) + N (Manifestation) = La manifestation d'une dispersion active dégradant la clarté de l'affichage (UI_GLITCH).

Description

Dégradation visuelle ou anomalie esthétique (Glitch) n'affectant pas nécessairement le Back-End, mais corrompant le Front-End (Enlaidir/Déformer).

Paire binaire : Z-Y-N

Mots du Coran issus de cette racine
