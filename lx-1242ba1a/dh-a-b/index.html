Racine DH-A-B (ذ أ ب) — Lexique Veritas (Maqasid al-Huruf)

ذ أ ب

Fonction logique : EMISSION_INSTANCE_BASE // BASED_EMISSION

Équation des lettres : DH (Émission) + A (Instanciation) + B (Base) = Émission instanciée prenant appui sur une base.

Description

Émission instanciée sur une base. L'émission (DH) instancie (A) une base (B) — émission ancrée sur une base.
