Racine R-H.-B (ر ح ب) — Lexique Veritas (Maqasid al-Huruf)

ر ح ب

Fonction logique : SPATIAL_EXPANSION // VOLUME_INCREASE

Équation des lettres : R (Cycle) + H. (Friction) + B (Base) = Cycle réduisant la friction sur la base, élargissant l'espace.

Description

Expansion spatiale. Le cycle (R) repousse les frictions (H.) de la base (B) — augmentation du volume disponible.

Paire binaire : D.-Y-Q
