Racine R-K-D (ر ك د) — Lexique Veritas (Maqasid al-Huruf)

ر ك د

Fonction logique : CYCLE_CAPTURE_VECTOR // FIXED_CAPTURED_CYCLE

Équation des lettres : R (Cycle) + K (Enfermement) + D (Vecteur_Fixe) = Cycle enfermé sur un vecteur fixe.

Description

Cycle enfermé sur un vecteur fixe. Le cycle (R) est enfermé (K) sur un vecteur fixe (D) — cycle retenu en position fixe.
