Racine H.-B-S (ح ب س) — Lexique Veritas (Maqasid al-Huruf)

Fonction logique : MEMORY_JAIL // PROCESS_ISOLATION

Équation des lettres : H. (Enceinte/Friction) + B (Base) + S (Flux) = La base formant une enceinte hermétique pour stopper net l'avancée du flux (MEMORY_JAIL).

Description
