Racine H.-Y-S. (ح ي ص) — Lexique Veritas (Maqasid al-Huruf)

ح ي ص

Fonction logique : FRICTION_ACTIVE_FOCAL // ACTIVATED_FOCAL_LIMIT

Équation des lettres : H. (Friction/Limite) + Y (Action_Active) + S. (Focale) = Friction activant une focale.

Description

Friction activée sur une focale. La friction (H.) active (Y) une focale (S.) — limite concentrée sur une focale.
