Racine SH-M-L (ش م ل) — Lexique Veritas (Maqasid al-Huruf)

ش م ل

Fonction logique : NEGATIVE_HANDSHAKE // LEFT_REGISTER

Équation des lettres : SH (Dispersion) + M (Matrice) + L (Allocation) = L'allocation dispersée dans la matrice, reléguée aux adresses secondaires (NEGATIVE_HANDSHAKE).

Description

Vecteur d'erreur ou processus de priorité basse situé sur le registre de rejet (Gauche/Nord).
