Racine F-R-H (ف ر ه) — Lexique Veritas (Maqasid al-Huruf)

ف ر ه

Fonction logique : OPEN_CYCLE_ENERGY // ENERGIZED_OPEN_CYCLE

Équation des lettres : F (Ouverture) + R (Cycle) + H (Énergie) = Ouverture cyclique chargée d'énergie.

Description

Ouverture cyclique énergisée. L'ouverture (F) entre en cycle (R) et s'énergise (H) — ouverture cyclique chargée d'énergie.
