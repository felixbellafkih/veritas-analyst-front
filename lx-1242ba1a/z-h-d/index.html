Racine Z-H-D (ز ه د) — Lexique Veritas (Maqasid al-Huruf)

ز ه د

Fonction logique : SEPARATION_ENERGY_VECTOR // ENERGY_DISENGAGEMENT

Équation des lettres : Z (Séparation) + H (Énergie) + D (Vecteur_Fixe) = Séparation de l'énergie du vecteur fixe.

Description

Désengagement énergétique. La séparation (Z) décharge l'énergie (H) du vecteur fixe (D) — retrait de l'énergie investie dans un vecteur.

Paire binaire : R-GH-B
