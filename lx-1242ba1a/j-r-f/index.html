Racine J-R-F (ج ر ف) — Lexique Veritas (Maqasid al-Huruf)

ج ر ف

Fonction logique : ASSEMBLY_CYCLE_OPEN // EROSION_SWEEP

Équation des lettres : J (Assemblage) + R (Cycle) + F (Ouverture) = Assemblage cyclique ouvrant la structure par érosion.

Description

Balayage érosif. L'assemblage (J) cycle (R) une ouverture (F) — le cycle d'ouverture désassemble progressivement la structure.

Paire binaire : TH-B-T
