Racine L-Y-S-A. (ل ي س ع) — Lexique Veritas (Maqasid al-Huruf)

ل ي س ع

Fonction logique : ALLOC_ACTIVE_FLUX_DEEP // EXPANDED_ACTIVE_FLOW

Équation des lettres : L (Allocation) + Y (Action_Active) + S (Flux) + A. (Connexion_Profonde)

Description

Nom propre coranique (اليسع). L (Allocation) + Y (Action_Active) + S (Flux) + A. (Connexion_Profonde) = Allocation active en flux de connexion profonde.

Présente dans 2 verset(s) du Coran

6:86, 38:48
