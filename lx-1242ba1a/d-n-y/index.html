Racine D-N-Y (د ن ي) — Lexique Veritas (Maqasid al-Huruf)

د ن ي

Fonction logique : VECTOR_MANIFEST_LINK // PROXIMITY_INTERFACE

Équation des lettres : D (Vecteur_Fixe) + N (Manifestation) + W (Lien) = Vecteur fixe manifestant un lien à proximité immédiate.

Description

Interface de proximité. Le vecteur fixe (D) manifeste (N) un lien (W) — position manifestée à distance minimale du point de référence. Couvre la proximité spatiale (داني) et l'environnement d'exécution immédiat (دنيا).

Paire binaire : Q-S.-Y
