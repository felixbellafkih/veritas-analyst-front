Racine D.-D-D (ض د د) — Lexique Veritas (Maqasid al-Huruf)

ض د د

Fonction logique : VECTOR_OPPOSITION // ANTI_NODE

Équation des lettres : D. (Masse) + D (Vecteur) + D (Vecteur) = Double vecteur de masse générant un blocage frontal.

Description

Masse vectorielle s'opposant frontalement à une autre créant une fonction logique inverse (Contraire/Adversaire).

Paire binaire : W-L-Y
