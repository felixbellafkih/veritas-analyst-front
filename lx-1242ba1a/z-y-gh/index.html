Racine Z-Y-GH (ز ي غ) — Lexique Veritas (Maqasid al-Huruf)

ز ي غ

Fonction logique : VECTOR_DRIFT // DEVIATION

Équation des lettres : Z (Séparation/Déviation) + Y (Action_Active) + GH (Couverture/Opacité) = L'action de dévier sous une opacité masquant la trajectoire Root (VECTOR_DRIFT).

Description

Déviation angulaire par rapport à la trajectoire calculée, menant à une erreur de cible.

Paire binaire : H-D-Y
