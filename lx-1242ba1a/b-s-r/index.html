Racine B-S-R (ب س ر) — Lexique Veritas (Maqasid al-Huruf)

ب س ر

Fonction logique : BASE_FLUX_CYCLE // CYCLED_BASE_FLUX

Équation des lettres : B (Base) + S (Flux) + R (Cycle) = Base libérant un flux soumis à un cycle.

Description

Flux de base en cycle. La base (B) libère un flux (S) qui entre en cycle (R) — flux issu de la base et ramené en cycle.
