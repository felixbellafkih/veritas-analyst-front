Racine L-L-A-T (ل ل ا ت) — Lexique Veritas (Maqasid al-Huruf)

ل ل ا ت

Fonction logique : ALLOC_ALLOC_INSTANCE_WAY // DOUBLE_ALLOCATED_ROUTED_INSTANCE

Équation des lettres : L (Allocation) + L (Allocation) + A (Instanciation) + T (Voie)

Description

Nom propre coranique (اللات). L (Allocation) + L (Allocation) + A (Instanciation) + T (Voie) = Double allocation instanciée sur une voie.

Présente dans 1 verset(s) du Coran

53:19

Lexique Veritas : chaque racine est décodée par la charge physique de ses lettres (Maqasid al-Huruf), sans recours aux dictionnaires historiques ni aux exégèses traditionnelles.
