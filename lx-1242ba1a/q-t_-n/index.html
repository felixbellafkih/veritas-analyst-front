Racine Q-T.-N (ق ط ن) — Lexique Veritas (Maqasid al-Huruf)

ق ط ن

Fonction logique : PRESSURE_SURFACE_MANIFEST // CLIMBING_GROWTH

Équation des lettres : Q (Pression) + T. (Surface) + N (Manifestation) = Pression de surface se manifestant en croissance.

Description

Croissance de surface. La pression (Q) de surface (T.) se manifeste (N) — émergence verticale par pression sur la surface.
