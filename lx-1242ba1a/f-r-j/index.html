Racine F-R-J (ف ر ج) — Lexique Veritas (Maqasid al-Huruf)

ف ر ج

Fonction logique : ASSEMBLY_CLEARANCE_CYCLE // PRESSURE_RELEASE

Équation des lettres : F (Ouverture) + R (Cycle) + J (Assemblage) = Ouverture cyclique d'un bloc assemblé.

Description

Ouverture cyclique dans un assemblage formant un point de passage ou de relâchement (Fissure/Soulagement).
