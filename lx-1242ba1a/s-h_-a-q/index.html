Racine S-H.-A-Q (س ح ا ق) — Lexique Veritas (Maqasid al-Huruf)

س ح ا ق

Fonction logique : FLUX_FRICTION_INSTANCE_PRESSURE // FRICTION_FLUX_PRESSURED_INSTANCE

Équation des lettres : S (Flux) + H. (Friction/Limite) + A (Instanciation) + Q (Pression)

Description

Nom propre coranique (إسحاق). S (Flux) + H. (Friction/Limite) + A (Instanciation) + Q (Pression) = Flux sous friction, instancié sous pression.
