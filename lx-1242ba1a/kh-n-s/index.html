Racine KH-N-S (خ ن س) — Lexique Veritas (Maqasid al-Huruf)

خ ن س

Fonction logique : STEALTH_RETRACTION // FURTIVE

Équation des lettres : KH (Extraction/Vide) + N (Manifestation) + S (Flux) = La manifestation d'un flux qui se retire et s'extrait du radar (STEALTH_RETRACTION).

Description

Processus se retirant ou se cachant brusquement après une phase d'activité pour éviter la détection.
