Racine N-D-D (ن د د) — Lexique Veritas (Maqasid al-Huruf)

ن د د

Fonction logique : SYSTEMIC_RIVAL // FALSE_EQUIVALENCE

Équation des lettres : N (Manifestation) + D (Vecteur_Fixe) + D (Vecteur_Fixe) = Manifestation de deux vecteurs fixes s'opposant en parité d'autorité (OPPOSING_PEER_NODE).

Description
