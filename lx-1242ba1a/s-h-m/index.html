Racine S-H-M (س ه م) — Lexique Veritas (Maqasid al-Huruf)

س ه م

Fonction logique : FLUX_ENERGY_MATRIX // MATRIX_ENERGY_FLUX

Équation des lettres : S (Flux) + H (Énergie) + M (Matrice) = Flux énergisé distribué dans une matrice.

Description

Flux énergisé en matrice. Le flux (S) s'énergise (H) dans une matrice (M) — flux d'énergie distribué par une matrice.
