Racine L-M-S (ل م س) — Lexique Veritas (Maqasid al-Huruf)

ل م س

Fonction logique : HAPTIC_PROBE // TOUCH

Équation des lettres : L (Allocation) + M (Matrice) + S (Flux_Surface) = L'allocation d'un flux glissant sur la surface d'une matrice pour en lire l'état (HAPTIC_PROBE).

Description

Interaction directe ou détection de contact physique entre deux interfaces matérielles.
