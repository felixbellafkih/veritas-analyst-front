Racine J-R-R (ج ر ر) — Lexique Veritas (Maqasid al-Huruf)

ج ر ر

Fonction logique : CONTINUOUS_TRACTION // SEQUENTIAL_PULL

Équation des lettres : J (Assemblage) + R (Cycle) + R (Cycle) = Double cycle de mouvement tractant l'assemblage.

Description

Maintien d'un assemblage dans un cycle de déplacement continu (Traction).

Paire binaire : D-F-A.

Mots du Coran issus de cette racine

MotTypeDéfinition
يَجُرُّهُVERB_FORM_ITracter ou forcer le déplacement d'un paquet de données.

Présente dans 1 verset(s) du Coran

7:150
