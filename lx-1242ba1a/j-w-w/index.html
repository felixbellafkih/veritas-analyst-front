Racine J-W-W (ج و و) — Lexique Veritas (Maqasid al-Huruf)

ج و و

Fonction logique : ASSEMBLY_DOUBLE_LINK // INTERIOR_SPACE

Équation des lettres : J (Assemblage) + W (Lien) + W (Lien) = Assemblage doublement lié formant un espace interne.

Description

Espace intérieur. L'assemblage (J) double-lie (W+W) — volume d'air assemblé entre deux liens (parois).
