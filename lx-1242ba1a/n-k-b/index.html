Racine N-K-B (ن ك ب) — Lexique Veritas (Maqasid al-Huruf)

ن ك ب

Fonction logique : PATH_DEVIATION // VECTOR_TILT

Équation des lettres : N (Manifestation) + K (Enfermement) + B (Base) = Manifestation d'un enfermement déviant la base.

Description

Glissement du vecteur d'exécution hors de sa trajectoire nominale (Déviation/Écartement).
