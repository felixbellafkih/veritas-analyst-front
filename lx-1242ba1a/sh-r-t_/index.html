Racine SH-R-T. (ش ر ط) — Lexique Veritas (Maqasid al-Huruf)

ش ر ط

Fonction logique : TRIGGER_CONDITION // LOGIC_FLAG

Équation des lettres : SH (Dispersion) + R (Cycle) + T. (Surface/Maintien) = Le maintien d'un cycle déclenché par l'apparition d'un marqueur en surface (TRIGGER_CONDITION).

Description

Marqueur logique (Flag) ou condition (If) stricte déclenchant l'exécution d'une routine (Condition/Signe).
