Racine F-N-N (ف ن ن) — Lexique Veritas (Maqasid al-Huruf)

ف ن ن

Fonction logique : OPEN_MANIFEST_MANIFEST // DOUBLE_MANIFEST_OPENING

Équation des lettres : F (Ouverture) + N (Manifestation) + N (Manifestation) = Ouverture produisant une manifestation redoublée.

Description

Ouverture en double manifestation. L'ouverture (F) manifeste (N) une manifestation redoublée (N) — ouverture qui se déploie en manifestations.
