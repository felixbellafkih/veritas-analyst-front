Racine L-Z-B (ل ز ب) — Lexique Veritas (Maqasid al-Huruf)

ل ز ب

Fonction logique : HARD_ADHERENCE // STICKY_BIND

Équation des lettres : L (Allocation) + Z (Séparation) + B (Base) = Allocation adhérant fortement à la base malgré la séparation.

Description

Adhérence extrême d'une allocation à son support, rendant toute séparation très coûteuse en CPU (Argile collante).
