Racine DH-A-M (ذ أ م) — Lexique Veritas (Maqasid al-Huruf)

ذ أ م

Fonction logique : DEGRADATION_TAG // SHAME_MARKER

Équation des lettres : DH (Émission) + A (Instanciation) + M (Matrice) = Émission instanciant une matrice de dépréciation.

Description

Marqueur de dégradation. L'émission (DH) instancie (A) une matrice (M) de dépréciation.

Paire binaire : K-R-M
