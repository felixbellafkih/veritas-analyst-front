Racine S-H-L (س ه ل) — Lexique Veritas (Maqasid al-Huruf)

س ه ل

Fonction logique : FLUX_ENERGY_ALLOC // LOW_FRICTION_SURFACE

Équation des lettres : S (Flux) + H (Énergie) + L (Allocation) = Flux énergisant une allocation à basse friction.

Description

Surface à basse friction. Le flux (S) énergise (H) une allocation (L) — le flux traverse l'allocation avec un minimum d'énergie de friction.
