Racine A.-R-R (ع ر ر) — Lexique Veritas (Maqasid al-Huruf)

ع ر ر

Fonction logique : DEEP_CYCLE_CYCLE // RECURSIVE_DEEP_CYCLE

Équation des lettres : A. (Connexion_Profonde) + R (Cycle) + R (Cycle) = Connexion profonde soumise à un cycle redoublé.

Description

Connexion profonde en double cycle. La connexion profonde (A.) entre dans un cycle (R) qui se redouble (R) — connexion reprise cycliquement.
