Racine H-SH-SH (ه ش ش) — Lexique Veritas (Maqasid al-Huruf)

ه ش ش

Fonction logique : CACHE_SWEEP // SURFACE_BEAT

Équation des lettres : H (Énergie) + SH (Dispersion) + SH (Dispersion) = Énergie de double dispersion nettoyant la surface.

Description

Application d'une énergie dispersive pour détacher et faire tomber des éléments résiduels (Frapper les feuilles).
