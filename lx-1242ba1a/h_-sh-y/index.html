Racine H.-SH-Y (ح ش ي) — Lexique Veritas (Maqasid al-Huruf)

ح ش ي

Fonction logique : FRICTION_DISPERSION_ACTIVE // PADDING

Équation des lettres : H. (Friction) + SH (Dispersion) + Y (Action_Active) = Action de densifier un espace par dispersion forcée.

Description

Action active de disperser de la matière sous friction pour remplir un vide interne (Remplissage).
