Racine GH-S.-B (غ ص ب) — Lexique Veritas (Maqasid al-Huruf)

غ ص ب

Fonction logique : FOCAL_BASE_USURPATION // FORCED_TAKEOVER

Équation des lettres : GH (Opacité) + S. (Focale) + B (Base) = Saisie illégitime d'une base par masquage focal.

Description

Base accaparée par une focalisation opaque sans validation de protocole (Usurpation/Vol).
