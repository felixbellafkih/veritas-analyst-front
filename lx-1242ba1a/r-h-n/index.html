Racine R-H-N (ر ه ن) — Lexique Veritas (Maqasid al-Huruf)

ر ه ن

Fonction logique : RESOURCE_FREEZE // LOCK_STATE

Équation des lettres : R (Cycle) + H (Énergie) + N (Manifestation_Figée) = Le cycle de l'énergie immobilisée et manifestée en attente de validation (RESOURCE_FREEZE).

Description

Gel temporaire d'une ressource ou d'un privilège en garantie d'une exécution future (Gage).
