Racine A-Y-N (أ ي ن) — Lexique Veritas (Maqasid al-Huruf)

أ ي ن

Fonction logique : SPATIAL_COORDINATE // POSITION_VECTOR

Équation des lettres : A (Instanciation) + Y (Vecteur_Actif) + N (Manifestation) = Instanciation d'un vecteur actif se manifestant dans l'espace (SPATIAL_COORDINATE).

Description

Vecteur de positionnement. Nœud d'identification de coordonnées spatiales au sein de la matrice.
