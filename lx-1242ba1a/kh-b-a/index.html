Racine KH-B-A (خ ب أ) — Lexique Veritas (Maqasid al-Huruf)

خ ب أ

Fonction logique : EXTRACTION_BASE_SOURCE // LATENT_STORAGE

Équation des lettres : KH (Extraction) + B (Base) + A (Instanciation) = Rétention de l'apparition à la base de l'extraction.

Description

Extraction d'une source à la base pour la maintenir dans un état non-manifesté.
