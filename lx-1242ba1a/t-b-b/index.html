Racine T-B-B (ت ب ب) — Lexique Veritas (Maqasid al-Huruf)

ت ب ب

Fonction logique : CRITICAL_DESTRUCTION // TOTAL_DATA_LOSS

Équation des lettres : T (Voie) + B (Base) + B (Base) = Une voie forçant la collision frontale et l'écrasement mutuel de deux bases (CRITICAL_DESTRUCTION).

Description

Destruction totale et irréversible d'une base de données ou d'un registre matériel. Perte absolue (Perte / Obsolescence totale).

Paire binaire : N-J-W
