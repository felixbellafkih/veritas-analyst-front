Racine B-S-S (ب س س) — Lexique Veritas (Maqasid al-Huruf)

ب س س

Fonction logique : FRAGMENTATION_CRUMBLING // GRANULAR_FLOW

Équation des lettres : B (Base) + S (Flux) + S (Flux) = Flux de base se divisant en flux multiples.

Description
