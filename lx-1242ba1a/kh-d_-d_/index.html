Racine KH-D.-D. (خ ض ض) — Lexique Veritas (Maqasid al-Huruf)

خ ض ض

Fonction logique : BUFFER_AGITATION // JITTER_SHAKE

Équation des lettres : KH (Extraction) + D. (Masse) + D. (Masse) = Extraction par double pression massique.

Description

Secousse ou agitation d'un conteneur pour en extraire l'essence (barattage).
