Racine GH-T.-SH (غ ط ش) — Lexique Veritas (Maqasid al-Huruf)

غ ط ش

Fonction logique : OPAQUE_SURFACE_DISPERSE // DARKNESS_SPREAD

Équation des lettres : GH (Opacité) + T. (Surface) + SH (Dispersion) = Opacité de surface se dispersant.

Description

Dispersion d'opacité en surface. L'opacité (GH) couvre la surface (T.) en dispersion (SH) — propagation de l'obscurité sur la surface.

Paire binaire : D.-W-A
