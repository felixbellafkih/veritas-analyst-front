Racine D-K-K (د ك ك) — Lexique Veritas (Maqasid al-Huruf)

د ك ك

Fonction logique : FIXED_CAPTURE_CAPTURE // STRUCTURAL_CRUSH

Équation des lettres : D (Impulsion) + K (Capture/Arrêt) + K (Capture) = Arrêt brutal répété nivelant la base.

Description

Double capture fixe écrasant les reliefs structurels pour niveler la matrice (Nivellement).
