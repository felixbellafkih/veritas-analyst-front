Racine D-H.-W (د ح و) — Lexique Veritas (Maqasid al-Huruf)

د ح و

Fonction logique : FIXED_FRICTION_LINK // SPATIAL_EXPANSION

Équation des lettres : D (Fixation) + H. (Friction/Limite) + W (Lien/Continuité) = Expansion d'un lien par friction de surface.

Description

Friction fixe sur un lien provoquant l'étalement ou l'expansion plane d'une base (Extension).
