Racine N-Q-D. (ن ق ض) — Lexique Veritas (Maqasid al-Huruf)

ن ق ض

Fonction logique : UNBUILD_ROUTINE // STRUCTURE_TEARDOWN

Équation des lettres : N (Manifestation) + Q (Pression) + D. (Masse) = La manifestation d'une pression détruisant la masse de l'assemblage (UNBUILD_ROUTINE).

Description

Action de défaire une structure scellée ou d'annuler une exécution en détruisant ses fondations (Démolir/Violer un serment).

Paire binaire : N-S-J
