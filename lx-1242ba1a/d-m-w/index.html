Racine D-M-W (د م و) — Lexique Veritas (Maqasid al-Huruf)

د م و

Fonction logique : FIXED_MATRIX_LINK // VITAL_STREAM

Description

Lien matriciel fixe assurant la circulation de l'énergie vitale (Sang).
