Racine N-F-H. (ن ف ح) — Lexique Veritas (Maqasid al-Huruf)

ن ف ح

Fonction logique : LIGHT_PULSE // BREEZE_SIGNAL

Équation des lettres : N (Manifestation) + F (Ouverture) + H. (Friction/Légère) = Manifestation d'une ouverture à très faible friction.

Description

Friction d'ouverture manifestant une légère impulsion ou un signal diffus (Souffle).
