Racine GH-R-B (غ ر ب) — Lexique Veritas (Maqasid al-Huruf)

غ ر ب

Fonction logique : SYSTEM_EXIT // DATA_SUNSET

Équation des lettres : GH (Couverture/Opacité) + R (Cycle) + B (Base) = L'opacité cyclique recouvrant la base pour marquer la fin de la visibilité du processus (SYSTEM_EXIT).

Description

Point de sortie final du flux ou terminaison du signal vers l'horizon non-adressable (Coucher/Ouest).

Paire binaire : T.-L-A.
