Racine L-F-T (ل ف ت) — Lexique Veritas (Maqasid al-Huruf)

ل ف ت

Fonction logique : PATH_DIVERSION // ATTENTION_SHIFT

Équation des lettres : L (Allocation) + F (Ouverture) + T (Voie) = Allocation forçant l'ouverture d'une nouvelle voie déviée.

Description

Action de forcer le pointeur d'une instance à se détourner de son axe d'exécution initial (Détourner).
