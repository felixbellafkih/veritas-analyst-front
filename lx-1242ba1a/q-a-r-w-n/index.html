Racine Q-A-R-W-N (ق ا ر و ن) — Lexique Veritas (Maqasid al-Huruf)

ق ا ر و ن

Fonction logique : PRESSURE_INSTANCE_CYCLE_LINK_MANIFEST // PRESSURED_CYCLIC_MANIFEST

Équation des lettres : Q (Pression) + A (Instanciation) + R (Cycle) + W (Lien) + N (Manifestation)

Description

Nom propre coranique (قارون). Q (Pression) + A (Instanciation) + R (Cycle) + W (Lien) + N (Manifestation) = Pression instanciée en cycle lié et manifesté.

Présente dans 4 verset(s) du Coran

28:76, 28:79, 29:39, 40:24

Lexique Veritas : chaque racine est décodée par la charge physique de ses lettres (Maqasid al-Huruf), sans recours aux dictionnaires historiques ni aux exégèses traditionnelles.
