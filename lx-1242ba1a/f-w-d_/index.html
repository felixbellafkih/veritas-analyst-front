Racine F-W-D. (ف و ض) — Lexique Veritas (Maqasid al-Huruf)

ف و ض

Fonction logique : LINK_PRESSURE_OPENING // DELEGATION_HANDOFF

Équation des lettres : F (Ouverture) + W (Lien) + D. (Masse) = Ouverture déléguant le maintien de la masse.

Description

Transfert d'un lien de pression massif vers une autre instance (Délégation/Remise de charge).
