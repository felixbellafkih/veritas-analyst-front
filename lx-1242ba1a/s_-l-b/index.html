Racine S.-L-B (ص ل ب) — Lexique Veritas (Maqasid al-Huruf)

ص ل ب

Définition 1

Fonction logique : FOCAL_ALLOC_BASE // RIGID_AXIS

Équation des lettres : S. (Focale) + L (Allocation) + B (Base) = Focalisation allouant rigidement vers la base.

Description

Axe focal de base. La focale (S.) alloue (L) vers la base (B) — un point de focalisation qui distribue rigidement vers la base. Désigne toute structure axiale rigide servant de support focal central.
