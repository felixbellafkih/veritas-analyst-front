Racine S-N-B-L (س ن ب ل) — Lexique Veritas (Maqasid al-Huruf)

س ن ب ل

Fonction logique : FLUX_MANIFEST_BASE_ALLOC // ALLOCATED_BASE_FLUX

Équation des lettres : S (Flux) + N (Manifestation) + B (Base) + L (Allocation) = Flux manifesté sur une base qui l'alloue.

Description

Flux manifesté sur une base allouée. Le flux (S) se manifeste (N) sur une base (B) qui l'alloue (L) — flux manifesté et réparti depuis une base.
