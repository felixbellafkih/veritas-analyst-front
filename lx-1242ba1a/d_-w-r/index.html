Racine D.-W-R (ض و ر) — Lexique Veritas (Maqasid al-Huruf)

ض و ر

Fonction logique : CYCLIC_STARVATION // RESOURCE_DISTRESS

Équation des lettres : D. (Masse) + W (Lien) + R (Cycle) = Cycle liant une masse à un état de privation.

Description

Lien cyclique forçant une masse dans un état de besoin ou d'épuisement extrême (Détresse/Affamé).
