Racine A-M-R (أ م ر) — Lexique Veritas (Maqasid al-Huruf)

أ م ر

Fonction logique : SYSTEM_EXECUTION_CALL // COMMAND

Équation des lettres : A (Instanciation) + M (Matrice) + R (Cycle/Ordre) = La source matricielle ordonne l'exécution d'un cycle (SYSTEM_EXECUTION_CALL).

Description
