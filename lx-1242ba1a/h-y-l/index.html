Racine H-Y-L (ه ي ل) — Lexique Veritas (Maqasid al-Huruf)

ه ي ل

Fonction logique : ENERGY_ACTIVE_ALLOC // ACTIVATED_ENERGY_ALLOCATION

Équation des lettres : H (Énergie) + Y (Action_Active) + L (Allocation) = Énergie activant une allocation.

Description

Énergie activée en allocation. L'énergie (H) active (Y) une allocation (L) — allocation mise en mouvement par l'énergie.
