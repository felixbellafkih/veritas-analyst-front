Racine D-H.-R (د ح ر) — Lexique Veritas (Maqasid al-Huruf)

د ح ر

Fonction logique : FIXED_FRICTION_CYCLE // EVICTION

Équation des lettres : D (Fixation/Poussée) + H. (Friction/Limite) + R (Cycle) = Cycle de poussée abrasive pour exclusion.

Description

Cycle de friction fixe visant à expulser un élément indésirable hors du périmètre de sécurité.

Paire binaire : A.-R-B
