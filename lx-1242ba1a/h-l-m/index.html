Racine H-L-M (ه ل م) — Lexique Veritas (Maqasid al-Huruf)

ه ل م

Fonction logique : FORCE_FETCH // BRING_TO_FRONT

Équation des lettres : H (Énergie) + L (Allocation) + M (Matrice) = Énergie allouant le rapatriement d'une matrice.

Description

Instruction forçant le rapatriement immédiat d'une instance ou d'une matrice vers le premier plan d'exécution.
