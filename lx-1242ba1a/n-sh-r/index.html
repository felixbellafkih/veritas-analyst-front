Racine N-SH-R (ن ش ر) — Lexique Veritas (Maqasid al-Huruf)

ن ش ر

Fonction logique : DATA_BROADCAST // NETWORK_EXPANSION

Équation des lettres : N (Manifestation) + SH (Dispersion) + R (Cycle) = La manifestation cyclique et dispersée d'un paquet sur toute l'interface (DATA_BROADCAST).
