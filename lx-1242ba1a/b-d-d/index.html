Racine B-D-D (ب د د) — Lexique Veritas (Maqasid al-Huruf)

ب د د

Fonction logique : VECTOR_SCATTERING // DISSIPATION

Équation des lettres : B (Base) + D (Vecteur) + D (Vecteur) = Dissipation d'une base par doubles vecteurs opposés.

Description

Base dispersée par de multiples vecteurs divergents entraînant l'éparpillement entropique des ressources.
