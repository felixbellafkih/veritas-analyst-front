Racine TH-L-L (ث ل ل) — Lexique Veritas (Maqasid al-Huruf)

ث ل ل

Fonction logique : COHORT_UNIT // GROUP_CLUSTER

Équation des lettres : TH (Résidu/Trace) + L (Allocation) + L (Allocation) = Double allocation d'un résidu formant un groupe.

Description

Unité de regroupement. Le résidu (TH) est alloué (L) puis réalloué (L) — formation d'un cluster cohérent.
