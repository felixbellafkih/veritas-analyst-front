Racine N-H.-Y (ن ح ي) — Lexique Veritas (Maqasid al-Huruf)

ن ح ي

Fonction logique : PORT_DIVERSION // SIDETRACK_VECTOR

Équation des lettres : N (Manifestation) + H. (Friction) + Y (Action_Active) = Action active de friction manifestant une déviation.

Description

Mise à l'écart volontaire d'un vecteur ou d'une ressource (Écarter/Mettre de côté).
