Racine T.-S-M (ط س م) — Lexique Veritas (Maqasid al-Huruf)

ط س م

Fonction logique : SEGMENT_HEADER_TRANS

Équation des lettres : T. (Marque/Init) + S (Flux) + M (Matrice) = Marque initiant le flux vers la matrice absolue (SEGMENT_HEADER_TRANS).

Description

Signal d'en-tête identifiant un bloc d'instructions de haute importance pour le compilateur.
