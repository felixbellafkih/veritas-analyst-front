و ج د

Fonction logique : INSTANCE_LOCALIZATION // ACTIVE_DISCOVERY

Équation des lettres : W (Lien) + J (Structure/Conteneur) + D (Vecteur_Fixe) = Établissement d'un lien vers une structure fixée (INSTANCE_LOCALIZATION).

Description
