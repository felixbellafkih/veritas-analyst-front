Racine S-Q-R (س ق ر) — Lexique Veritas (Maqasid al-Huruf)

س ق ر

Fonction logique : FLUX_PRESSURE_CYCLE // PRESSURED_FLUX_CYCLE

Équation des lettres : S (Flux) + Q (Pression) + R (Cycle)

Description

Nom propre coranique (سقر). S (Flux) + Q (Pression) + R (Cycle) = Flux sous pression en cycle.

Présente dans 4 verset(s) du Coran

54:48, 74:26, 74:27, 74:42
