Racine H.-T.-T. (ح ط ط) — Lexique Veritas (Maqasid al-Huruf)

ح ط ط

Fonction logique : LOAD_DISCHARGE // WEIGHT_REMOVAL

Équation des lettres : H. (Friction) + T. (Surface) + T. (Surface) = Friction de double surface opérant un délestage.

Description

Décharge de charge. La friction (H.) sur une double surface (T.+T.) opère un délestage — retrait d'un poids.

Paire binaire : H.-M-L
