Racine W-K-L (و ك ل) — Lexique Veritas (Maqasid al-Huruf)

و ك ل

Fonction logique : PROXY_AGENT // DELEGATED_AUTHORITY

Équation des lettres : W (Lien) + K (Enfermement/Capture) + L (Allocation) = Le lien capturant une allocation pour agir en son nom (PROXY_AGENT).

Description

Instance mandatée pour agir en tant que Proxy, héritant temporairement des autorisations du Root ou d'un nœud appelant (Garant/Mandataire).
