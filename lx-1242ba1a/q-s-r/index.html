Racine Q-S-R (ق س ر) — Lexique Veritas (Maqasid al-Huruf)

ق س ر

Fonction logique : PRESSURE_FLUX_CYCLE // PRESSURED_FLUX_CYCLE

Équation des lettres : Q (Pression) + S (Flux) + R (Cycle) = Pression imposée à un flux cyclique.

Description

Flux sous pression en cycle. La pression (Q) contraint un flux (S) en cycle (R) — flux soumis à une pression cyclique.
