Racine KH-R-S (خ ر س) — Lexique Veritas (Maqasid al-Huruf)

خ ر س

Fonction logique : EXTRACTION_CYCLE_FLUX // MUTE_STATE

Équation des lettres : KH (Extraction/Vide) + R (Cycle) + S (Flux) = Vide de flux au sein du cycle.

Description

Extraction du flux d'un cycle rendant l'interface incapable d'émettre des paquets (Mutisme).

Paire binaire : N-T.-Q
