Racine KH-N-Z-R (خ ن ز ر) — Lexique Veritas (Maqasid al-Huruf)

خ ن ز ر

Fonction logique : CONTAMINATED_ORGANISM // TOXIC_BIOAGENT

Équation des lettres : KH (Extraction) + N (Manifestation) + Z (Déviation) + R (Cycle) = Extraction manifestant un cycle de déviation toxique.

Description

Organisme porteur de contamination. Entité biologique dont l'extraction (KH) manifeste (N) une déviation (Z) cyclique (R).
