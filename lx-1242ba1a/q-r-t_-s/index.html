Racine Q-R-T.-S (ق ر ط س) — Lexique Veritas (Maqasid al-Huruf)

ق ر ط س

Fonction logique : FLAT_SURFACE_MEDIUM // INSCRIPTION_CARRIER

Équation des lettres : Q (Pression) + R (Cycle) + T. (Surface) + S (Flux) = Pression cyclique sur une surface transportant un flux.

Description

Support d'inscription plat. La pression (Q) cycle (R) une surface (T.) en flux (S) — médium de transport d'information.
