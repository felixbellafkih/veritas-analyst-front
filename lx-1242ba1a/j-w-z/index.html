Racine J-W-Z (ج و ز) — Lexique Veritas (Maqasid al-Huruf)

ج و ز

Fonction logique : ASSEMBLY_TRANSIT // PORT_CROSSING

Équation des lettres : J (Assemblage) + W (Lien) + Z (Séparation/Émergence) = Lien d'assemblage franchissant une ligne de séparation.

Description

Assemblage d'un lien permettant le passage séparé d'une zone à une autre (Traversée/Permission).

Paire binaire : H.-J-B
