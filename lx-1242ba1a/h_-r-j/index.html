Racine H.-R-J (ح ر ج) — Lexique Veritas (Maqasid al-Huruf)

ح ر ج

Fonction logique : NARROW_THROTTLING // EXECUTION_NARROWNESS

Équation des lettres : H. (Limite) + R (Cycle) + J (Assemblage) = Assemblage contraint dans une limite cyclique restreinte.

Description

Assemblage cyclique atteignant une limite étroite, générant une gêne matérielle ou une restriction de bande passante (Gêne/Étroitesse).

Paire binaire : W-S-A.
