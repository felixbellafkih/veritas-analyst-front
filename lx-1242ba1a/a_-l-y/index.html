Racine A.-L-Y (ع ل ى) — Lexique Veritas (Maqasid al-Huruf)

ع ل ى

Fonction logique : VEC_OVER // LOAD_SUPERPOSITION

Équation des lettres : A. (Connexion_Profonde) + L (Allocation) + Y (Action_Active/Élévation) = La connexion alloue une action de superposition dominante (VEC_OVER).

Description

Vecteur de charge. Désigne une superposition avec contact (physique ou logique). Applique une charge, un poids, une responsabilité ou une domination sur le nœud cible.

Paire binaire : S-F-L
