Racine Z-N-J-B-L (ز ن ج ب ل) — Lexique Veritas (Maqasid al-Huruf)

ز ن ج ب ل

Fonction logique : SEPARATE_MANIFEST_ASSEMBLE_BASE_ALLOC // AROMATIC_COMPOUND

Équation des lettres : Z (Séparation) + N (Manifestation) + J (Assemblage) + B (Base) + L (Allocation) = Séparation manifestant un assemblage alloué à la base.

Description

Composé aromatique. La séparation (Z) manifeste (N) un assemblage (J) sur la base (B) allouée (L) — substance dont la séparation libère un assemblage manifeste.
