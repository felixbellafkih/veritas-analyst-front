Racine F-D.-Y (ف ض ي) — Lexique Veritas (Maqasid al-Huruf)

ف ض ي

Fonction logique : SPACE_CLEARANCE // MASS_EVACUATION

Équation des lettres : F (Ouverture) + D. (Masse) + Y (Action_Active) = Ouverture active libérant la pression massique.

Description

Action active d'ouvrir une masse pressurisée pour libérer son espace (Vider/Évacuer).

Paire binaire : H.-SH-R
