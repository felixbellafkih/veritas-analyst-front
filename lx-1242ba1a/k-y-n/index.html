Racine K-Y-N (ك ي ن) — Lexique Veritas (Maqasid al-Huruf)

ك ي ن

Fonction logique : CAPTURE_ACTIVE_MANIFEST // CONTAINED_MANIFESTATION

Équation des lettres : K (Enfermement) + Y (Action_Active) + N (Manifestation) = Enfermement activant une manifestation.

Description

Enfermement activé en manifestation. L'enfermement (K) active (Y) une manifestation (N) — manifestation contenue par l'enfermement.
