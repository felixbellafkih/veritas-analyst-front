Racine N-K-F (ن ك ف) — Lexique Veritas (Maqasid al-Huruf)

ن ك ف

Fonction logique : HARD_REJECT // REQUEST_DENIAL

Équation des lettres : N (Manifestation) + K (Enfermement) + F (Ouverture/Séparation) = Manifestation d'un enfermement séparateur.

Description

Rejet net, hautain et immédiat d'une requête d'accès (Refus/Répugnance).

Mots du Coran issus de cette racine

MotTypeDéfinition
يَسْتَنْكِفَVERB_FORM_XExécuter une routine d'évitement par refus de l'instruction.

Présente dans 2 verset(s) du Coran
