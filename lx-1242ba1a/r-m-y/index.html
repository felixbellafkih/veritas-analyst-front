Racine R-M-Y (ر م ي) — Lexique Veritas (Maqasid al-Huruf)

ر م ي

Fonction logique : PACKET_EMISSION // VECTOR_INJECTION

Équation des lettres : R (Cycle) + M (Matrice) + Y (Action_Active) = Action active de la matrice projetant un cycle vers l'extérieur (PACKET_EMISSION).

Description

Projection d'un vecteur de données vers une cible externe. Envoi de paquets (Lancer/Jeter).
