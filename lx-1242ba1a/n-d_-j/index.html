Racine N-D.-J (ن ض ج) — Lexique Veritas (Maqasid al-Huruf)

ن ض ج

Fonction logique : THERMAL_MATURATION // READY_STATE

Équation des lettres : N (Manifestation) + D. (Masse/Chaleur) + J (Assemblage) = Manifestation d'une masse assemblée sous la chaleur.

Description

Assemblage de masse manifestant un état de cuisson ou de préparation achevée, prêt à l'exécution.
