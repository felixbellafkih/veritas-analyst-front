Racine DH-Q-N (ذ ق ن) — Lexique Veritas (Maqasid al-Huruf)

ذ ق ن

Fonction logique : LOWER_SUPPORT_EMISSION // BASE_PIVOT

Équation des lettres : DH (Émission) + Q (Pression) + N (Manifestation) = Manifestation de la pression d'appui.

Description

Manifestation d'une pression émise à l'extrémité inférieure d'une structure, servant de point d'appui physique.
