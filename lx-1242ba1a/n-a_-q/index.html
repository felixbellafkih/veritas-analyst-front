Racine N-A.-Q (ن ع ق) — Lexique Veritas (Maqasid al-Huruf)

ن ع ق

Fonction logique : PING_BROADCAST // WAKE_UP_CALL

Équation des lettres : N (Manifestation) + A. (Connexion) + Q (Pression/Émission) = Manifestation d'une pression sonore sur la connexion.

Description

Pression connectée émettant un signal de réveil ou d'alerte sur le réseau (Croassement/Cri).

Mots du Coran issus de cette racine

MotTypeDéfinition
يَنْعِقُVERB_FORM_IÉmettre un Ping Broadcast pour réveiller les instances en veille.

Présente dans 1 verset(s) du Coran
