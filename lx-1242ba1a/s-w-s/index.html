Racine S-W-S (س و س) — Lexique Veritas (Maqasid al-Huruf)

س و س

Fonction logique : FLUX_LINK_FLUX // CYCLIC_INFILTRATION

Équation des lettres : S (Flux) + W (Lien) + S (Flux) = Flux lié à un flux formant une boucle d'infiltration.

Description

Infiltration cyclique. Le flux (S) se lie (W) à un flux (S) — boucle de flux qui s'auto-alimente en s'infiltrant dans le système.
