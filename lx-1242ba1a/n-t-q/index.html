Racine N-T-Q (ن ت ق) — Lexique Veritas (Maqasid al-Huruf)

ن ت ق

Fonction logique : FORCE_EXTRACT // HARDWARE_SHAKE

Équation des lettres : N (Manifestation) + T (Voie) + Q (Pression) = Manifestation d'une pression sur la voie d'ancrage.

Description

Arrachement matériel provoquant une secousse de la base (Secouer/Extraire violemment).
