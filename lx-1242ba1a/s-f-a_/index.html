Racine S-F-A. (س ف ع) — Lexique Veritas (Maqasid al-Huruf)

س ف ع

Fonction logique : FLUX_OPEN_DEEP // FORCEFUL_SEIZE

Équation des lettres : S (Flux) + F (Ouverture) + A. (Connexion_Profonde) = Flux ouvrant une connexion profonde par force.

Description

Saisie forcée. Le flux (S) ouvre (F) une connexion profonde (A.) — pénétration du flux par ouverture en connexion profonde.
