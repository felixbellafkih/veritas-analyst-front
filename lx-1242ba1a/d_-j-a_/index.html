Racine D.-J-A. (ض ج ع) — Lexique Veritas (Maqasid al-Huruf)

ض ج ع

Fonction logique : DEEP_MASS_ASSEMBLY // HORIZONTAL_STASIS

Équation des lettres : D. (Masse) + J (Assemblage) + A. (Connexion/Profondeur) = Ancrage profond d'une masse immobilisée.

Description

Assemblage d'une masse en connexion profonde, forçant la structure dans un état d'immobilisation à l'horizontale (Couché/Repos).
