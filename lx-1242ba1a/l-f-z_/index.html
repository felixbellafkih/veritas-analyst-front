Racine L-F-Z. (ل ف ظ) — Lexique Veritas (Maqasid al-Huruf)

ل ف ظ

Fonction logique : OUTPUT_EXPULSION // VERBAL_DUMP

Équation des lettres : L (Allocation) + F (Ouverture) + Z. (Ombre/Masse_Lourde) = Allocation expulsant une masse par une ouverture.

Description

Émission d'une chaîne de caractères ou de données vers le port externe (Prononcer/Jeter).
