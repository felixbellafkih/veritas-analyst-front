Racine Q-SH-A.-R (ق ش ع ر) — Lexique Veritas (Maqasid al-Huruf)

ق ش ع ر

Fonction logique : PRESSURE_DISPERSE_DEEP_CYCLE // SURFACE_CONTRACTION

Équation des lettres : Q (Pression) + SH (Dispersion) + A. (Connexion_Profonde) + R (Cycle) = Pression dispersive cyclique contractant la surface.

Description

Contraction de surface. La pression (Q) disperse (SH) la connexion profonde (A.) en cycle (R) — la surface se contracte sous l'effet d'une pression dispersive cyclique.
