Racine F-Y-D. (ف ي ض) — Lexique Veritas (Maqasid al-Huruf)

ف ي ض

Fonction logique : ACTIVE_MASS_OPENING // CRITICAL_OVERFLOW

Équation des lettres : F (Ouverture) + Y (Action_Active) + D. (Masse) = Ouverture soudaine d'une masse d'énergie.

Description

Ouverture active d'une masse pressurisée générant un débordement incontrôlable (Débordement/Inondation).

Paire binaire : GH-Y-D.
