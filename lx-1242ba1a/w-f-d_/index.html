Racine W-F-D. (و ف ض) — Lexique Veritas (Maqasid al-Huruf)

و ف ض

Fonction logique : LINK_OPEN_PRESSURE // PRESSURED_DISPATCH

Équation des lettres : W (Lien) + F (Ouverture) + D. (Masse) = Lien ouvrant une pression de déplacement.

Description

Envoi sous pression. Le lien (W) ouvre (F) une pression (D.) — déplacement lié sous pression vers une destination.
