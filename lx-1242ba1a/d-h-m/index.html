Racine D-H-M (د ه م) — Lexique Veritas (Maqasid al-Huruf)

د ه م

Fonction logique : FIXED_ENERGY_MATRIX // SUDDEN_OVERLAY

Équation des lettres : D (Vecteur_Fixe) + H (Énergie) + M (Matrice) = Énergie couvrant la matrice via un vecteur fixe.

Description

Énergie fixe recouvrant la matrice de manière soudaine et totale (Obscurcissement).

Paire binaire : D.-W-A
