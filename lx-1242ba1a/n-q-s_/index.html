Racine N-Q-S. (ن ق ص) — Lexique Veritas (Maqasid al-Huruf)

ن ق ص

Fonction logique : RESOURCE_DECREMENT // CAPACITY_DROP

Équation des lettres : N (Manifestation) + Q (Pression) + S. (Focale/Contraction) = La manifestation d'une pression contractant l'allocation globale (RESOURCE_DECREMENT).

Description

Indicateur de réduction des actifs, de la puissance ou de la capacité de stockage (Diminution/Manque).

Paire binaire : K-M-L
