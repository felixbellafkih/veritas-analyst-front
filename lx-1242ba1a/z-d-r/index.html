Racine Z-D-R (ز د ر) — Lexique Veritas (Maqasid al-Huruf)

ز د ر

Fonction logique : SEPARATION_VECTOR_CYCLE // DOWNWARD_SEPARATION

Équation des lettres : Z (Séparation) + D (Vecteur_Fixe) + R (Cycle) = Séparation vectorielle cyclique descendante.

Description

Séparation vectorielle descendante. La séparation (Z) fixe un vecteur (D) cyclique (R) — cycle de séparation dirigé vers le bas.

Paire binaire : K-R-M
