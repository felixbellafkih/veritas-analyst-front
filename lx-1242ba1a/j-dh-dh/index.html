Racine J-DH-DH (ج ذ ذ) — Lexique Veritas (Maqasid al-Huruf)

ج ذ ذ

Fonction logique : ASSEMBLY_FRAGMENTATION // SHREDDING

Équation des lettres : J (Assemblage) + DH (Séparation) + DH (Séparation) = Rupture de l'assemblage par double émission de forces divergentes.

Description

Action de désassembler un bloc par émission de forces séparatrices, le réduisant en micro-fragments.
