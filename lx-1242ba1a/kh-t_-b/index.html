Racine KH-T.-B (خ ط ب) — Lexique Veritas (Maqasid al-Huruf)

خ ط ب

Fonction logique : EXTRACTION_SURFACE_BASE // DIRECT_ADDRESS

Équation des lettres : KH (Extraction) + T. (Surface) + B (Base) = Sortie de la base vers l'interface de surface.

Description

Extraction de la base vers la surface pour une communication ou une requête directe (Discours/Requête).
