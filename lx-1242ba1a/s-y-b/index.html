Racine S-Y-B (س ي ب) — Lexique Veritas (Maqasid al-Huruf)

س ي ب

Fonction logique : FLUX_ACTIVE_BASE // ACTIVATED_FLUX_BASE

Équation des lettres : S (Flux) + Y (Action_Active) + B (Base) = Flux activant une base.

Description

Flux activant une base. Le flux (S) active (Y) une base (B) — base mise en mouvement par un flux activé.
