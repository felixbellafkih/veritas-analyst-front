Racine T-F-TH (ت ف ث) — Lexique Veritas (Maqasid al-Huruf)

ت ف ث

Fonction logique : WAY_OPEN_DENSITY // ACCUMULATED_RESIDUE

Équation des lettres : T (Voie) + F (Ouverture) + TH (Densité) = Voie ouvrant une accumulation de densité résiduelle.

Description

Résidu accumulé. La voie (T) ouvre (F) une densité (TH) — accumulation de matière dense sur une voie nécessitant une purge.

Paire binaire : T.-H-R
