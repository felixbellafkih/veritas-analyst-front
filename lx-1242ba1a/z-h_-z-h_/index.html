Racine Z-H.-Z-H. (ز ح ز ح) — Lexique Veritas (Maqasid al-Huruf)

Fonction logique : FORCED_DISPLACEMENT // STATE_SHIFT

Équation des lettres : Z-H (Compression/Poussée) x 2 = Poussée répétée provoquant un décalage d'état (FORCED_DISPLACEMENT).

Description

Matrice quadrilitère. Déplacement forcé d'une instance hors de son ancrage ou de sa boucle de traitement initiale par application d'une poussée itérative.
