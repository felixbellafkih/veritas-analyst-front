Racine W-D-Y (و د ي) — Lexique Veritas (Maqasid al-Huruf)

و د ي

Fonction logique : COMPENSATION_TRANSFER // VALUE_RESTITUTION

Équation des lettres : W (Lien) + D (Vecteur_Fixe) + Y (Action_Active) = Lien fixant un vecteur actif de compensation.

Description

Transfert compensatoire. Le lien (W) fixe un vecteur (D) actif (Y) — restitution de valeur pour compenser une perte.
