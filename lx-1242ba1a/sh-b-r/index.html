Racine SH-B-R (ش ب ر) — Lexique Veritas (Maqasid al-Huruf)

ش ب ر

Fonction logique : SPAN_MEASUREMENT // CYCLE_WIDTH

Équation des lettres : SH (Dispersion) + B (Base) + R (Cycle) = Cycle de base dispersif mesurable.

Description

Dispersion mesurée de la base sur un cycle. 🚨 SÉCURITÉ KERNEL : Désigne la largeur d'une trame ou la portée d'un index de distance courte (Empan).
