Racine KH-F-T (خ ف ت) — Lexique Veritas (Maqasid al-Huruf)

خ ف ت

Fonction logique : SIGNAL_ATTENUATION // LOW_AMPLITUDE

Équation des lettres : KH (Extraction) + F (Ouverture) + T (Voie) = Extraction d'une ouverture sur une voie atténuée.

Description

Atténuation de signal. L'extraction (KH) ouvre (F) une voie (T) à basse amplitude.

Paire binaire : J-H-R
