Racine L-Y-S (ل ي س) — Lexique Veritas (Maqasid al-Huruf)

ل ي س

Fonction logique : NULL_STATE // VOID_ALLOCATION

Équation des lettres : L (Allocation) + Y (Vecteur_Actif) + S (Flux_Fuyant) = L'allocation d'un vecteur qui s'écoule dans le vide (NULL_STATE).

Description

Négation d'un état ou d'une appartenance. Constat d'une allocation vide ou d'une non-correspondance entre deux clusters (Is_Not).

Paire binaire : K-W-N
