Racine W (و) — Lexique Veritas (Maqasid al-Huruf)

و

Fonction logique : OP_AND // INCLUSIVE_ADDITION

Équation des lettres : W (Lien) = Vecteur d'attache pur, liant une variable au registre sans écraser la précédente (INCLUSIVE_ADDITION).

Description

Opérateur logique d'addition inclusive. Associe deux variables ou processus dans le même état ou registre, sans imposer d'ordre chronologique ou hiérarchique.
