Racine Q-S.-Y (ق ص ي) — Lexique Veritas (Maqasid al-Huruf)

ق ص ي

Fonction logique : EXTREME_EDGE_NODE // MAX_DISTANCE

Équation des lettres : Q (Pression) + S. (Focale) + Y (Action_Active/Éloignement) = La pression focale poussant l'action d'une variable à l'extrême limite du système (EXTREME_EDGE_NODE).

Description

Le nœud le plus éloigné de l'architecture sur un vecteur donné. Limite extrême du périmètre réseau (Terminal Edge).

Paire binaire : D-N-W
