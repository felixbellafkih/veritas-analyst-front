Racine F-Q-A. (ف ق ع) — Lexique Veritas (Maqasid al-Huruf)

ف ق ع

Fonction logique : PEAK_INTENSITY // PURE_RADIANCE

Équation des lettres : F (Ouverture/Émergence) + Q (Pression/Maintien) + A. (Connexion profonde) = L'émergence d'une pression interne créant une intensité absolue (PEAK_INTENSITY).

Description

Intensité maximale d'une manifestation, éclat pur sans altération, saturation absolue d'une fréquence ou d'un état.

Mots du Coran issus de cette racine

MotTypeDéfinition
فَاقِعٌBASE_VARIABLEInstance dont la fréquence (couleur) a atteint une saturation absolue et éclatante, attirant irrésistiblement le focus.

Présente dans 1 verset(s) du Coran

2:69
