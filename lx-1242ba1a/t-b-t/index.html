Racine T-B-T (ت ب ت) — Lexique Veritas (Maqasid al-Huruf)

ت ب ت

Fonction logique : SEALED_CONTAINER // ARCHIVE_VESSEL

Équation des lettres : T (Voie) + B (Base) + T (Voie) = Double voie encapsulant la base.

Description

Conteneur scellé. La voie (T) encapsule la base (B) puis rescelle par une voie (T) — structure d'archivage hermétique.
