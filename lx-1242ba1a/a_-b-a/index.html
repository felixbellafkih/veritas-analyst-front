Racine A.-B-A (ع ب أ) — Lexique Veritas (Maqasid al-Huruf)

ع ب أ

Fonction logique : DEEP_CONNECT_BASE_INSTANCE // LOAD_CONCERN

Équation des lettres : A. (Connexion_Profonde) + B (Base) + A (Instanciation) = Connexion profonde chargeant la base d'une instanciation.

Description

Charge sur la connexion de base. La connexion profonde (A.) charge la base (B) d'une instanciation (A) — attribution d'un poids ou d'une importance à la base.
