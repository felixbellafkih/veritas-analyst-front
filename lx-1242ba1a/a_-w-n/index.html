Racine A.-W-N (ع و ن) — Lexique Veritas (Maqasid al-Huruf)

ع و ن

Fonction logique : INTERMEDIATE_NODE // AUXILIARY_SUPPORT

Équation des lettres : A. (Connexion) + W (Lien) + N (Nœud) = Un nœud de liaison opérant comme intermédiaire ou support (INTERMEDIATE_NODE).

Description

État médian, équilibre entre deux extrêmes (âge moyen), ou instance servant de support/assistance entre deux points.
