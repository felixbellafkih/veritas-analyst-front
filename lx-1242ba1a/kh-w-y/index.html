Racine KH-W-Y (خ و ي) — Lexique Veritas (Maqasid al-Huruf)

خ و ي

Fonction logique : EXTRACTION_LINK_ACTIVE // VACUITY

Équation des lettres : KH (Extraction/Vide) + W (Lien) + Y (Action_Active) = Action de vider le lien d'une structure.

Description

Action active d'extraire le lien provoquant l'effondrement ou la vacuité d'une structure (Vide).

Paire binaire : A.-M-R
