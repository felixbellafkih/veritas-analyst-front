Racine N-F-Y (ن ف ي) — Lexique Veritas (Maqasid al-Huruf)

ن ف ي

Fonction logique : NODE_BANISHMENT // REJECT_RULE

Équation des lettres : N (Manifestation) + F (Ouverture/Rejet) + Y (Action_Active) = Manifestation active du rejet.

Description

Action d'ouverture manifestant l'effacement ou l'exil d'une instance hors de la table d'allocation système.

MotTypeDéfinition
