Racine A.-Y-S-Y (ع ي س ي) — Lexique Veritas (Maqasid al-Huruf)

ع ي س ي

Fonction logique : DEEP_ACTIVE_FLUX_ACTIVE // DOUBLE_ACTIVE_DEEP_FLUX

Équation des lettres : A. (Connexion_Profonde) + Y (Action_Active) + S (Flux) + Y (Action_Active)

Description

Nom propre coranique (عيسى). A. (Connexion_Profonde) + Y (Action_Active) + S (Flux) + Y (Action_Active) = Connexion profonde en double action active de flux.
