Racine R-K-N (ر ك ن) — Lexique Veritas (Maqasid al-Huruf)

ر ك ن

Fonction logique : STRUCTURAL_PILLAR // ANCHOR_POINT

Équation des lettres : R (Cycle) + K (Capture/Verrou) + N (Manifestation) = Cycle capturé manifestant une fixation matérielle (STRUCTURAL_PILLAR).

Description
