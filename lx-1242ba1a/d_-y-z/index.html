Racine D.-Y-Z (ض ي ز) — Lexique Veritas (Maqasid al-Huruf)

ض ي ز

Fonction logique : PRESSURE_ACTIVE_SEPARATION // SKEWED_PARTITION

Équation des lettres : D. (Masse) + Y (Action_Active) + Z (Séparation) = Pression active produisant une séparation déséquilibrée.

Description

Partition biaisée. La pression (D.) active (Y) une séparation (Z) — répartition déséquilibrée par pression active.

Paire binaire : A.-D-L
