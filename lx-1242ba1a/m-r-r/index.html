Racine M-R-R (م ر ر) — Lexique Veritas (Maqasid al-Huruf)

م ر ر

Fonction logique : HARSH_TRANSIT // BITTER_LOOP

Équation des lettres : M (Matrice) + R (Cycle) + R (Cycle) = Répétition cyclique lourde sur la matrice.

Description

Cycle de transit forcé et difficile, ou itération redondante provoquant une friction amère.
