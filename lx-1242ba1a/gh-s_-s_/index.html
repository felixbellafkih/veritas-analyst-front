Racine GH-S.-S. (غ ص ص) — Lexique Veritas (Maqasid al-Huruf)

غ ص ص

Fonction logique : OPAQUE_FOCAL_FOCAL // FOCUSED_OPACITY

Équation des lettres : GH (Opacité) + S. (Focale) + S. (Focale) = Opacité concentrée sur une double focale.

Description

Opacité en double focale. L'opacité (GH) se focalise (S.) en un point redoublé (S.) — opacité concentrée sur une focale.
