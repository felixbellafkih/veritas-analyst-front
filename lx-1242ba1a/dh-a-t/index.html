Racine DH-A-T (ذ ا ت) — Lexique Veritas (Maqasid al-Huruf)

ذ ا ت

Fonction logique : INTRINSIC_POSSESSOR // SELF_REFERENCE

Équation des lettres : DH (Émission) + A (Instanciation) + T (Voie) = Émission d'une instanciation sur une voie interne.

Description

Pointeur d'appartenance intrinsèque. Émission (DH) d'une instanciation (A) sur une voie (T) — désigne la nature propre ou l'essence interne d'une entité.
