Racine N-B-Z (ن ب ز) — Lexique Veritas (Maqasid al-Huruf)

ن ب ز

Fonction logique : TAG_OVERRIDE // LABEL_SWAP

Équation des lettres : N (Manifestation) + B (Base) + Z (Séparation) = Manifestation séparant la base de son identifiant.

Description

Séparation de base manifestant un renommage forcé ou l'application d'un Alias altérant la signature.
