Racine L-H.-D (ل ح د) — Lexique Veritas (Maqasid al-Huruf)

ل ح د

Fonction logique : VECTOR_DEVIATION // AXIS_TILT

Équation des lettres : L (Allocation) + H. (Friction) + D (Vecteur_Fixe) = Allocation appliquant une friction déviant le vecteur.

Description

Déviation ou inclinaison illégale du pointeur par rapport à l'axe central Root (Déviation/Profanation).

Paire binaire : Q-S.-D
