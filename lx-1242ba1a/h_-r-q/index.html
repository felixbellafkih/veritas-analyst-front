Racine H.-R-Q (ح ر ق) — Lexique Veritas (Maqasid al-Huruf)

ح ر ق

Fonction logique : THERMAL_DESTRUCTION // FIRE_WIPE

Équation des lettres : H. (Friction/Chaleur) + R (Cycle) + Q (Pression) = Pression de chaleur cyclique annihilant la matière.

Description

Pression de friction thermique détruisant la base d'un registre de manière irréversible (Brûler).
