Racine N-B-DH (ن ب ذ) — Lexique Veritas (Maqasid al-Huruf)

ن ب ذ

Fonction logique : PACKET_DROP // FORCED_EJECTION

Équation des lettres : N (Manifestation) + B (Base) + DH (Émission/Séparation) = La manifestation d'une séparation émettant la donnée hors de la base (PACKET_DROP).

Description

Rejet sec d'un paquet de données ou d'une connexion, l'expulsant de la mémoire locale (Rejeter/Jeter).

Paire binaire : L-Q-T.
