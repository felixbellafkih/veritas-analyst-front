Racine L-Q-B (ل ق ب) — Lexique Veritas (Maqasid al-Huruf)

ل ق ب

Fonction logique : ALIAS_TAGGING // SECONDARY_ID

Équation des lettres : L (Allocation) + Q (Pression) + B (Base) = Allocation forçant un tag sur la base.

Description

Attribution d'un identifiant ou d'un flag secondaire, souvent dépréciatif (Surnom/Titre).

Paire binaire : S-M-Y
