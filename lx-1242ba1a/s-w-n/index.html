Racine S-W-N (س و ن) — Lexique Veritas (Maqasid al-Huruf)

س و ن

Fonction logique : DATA_PRESERVATION // MAINTAIN_STATE

Équation des lettres : S (Flux) + W (Lien) + N (Manifestation_Gardée) = Flux protégeant la manifestation du lien.

Description

Protection d'un registre contre les altérations. Maintien en état sécurisé (Préserver/Garder).
