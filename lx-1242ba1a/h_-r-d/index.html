Racine H.-R-D (ح ر د) — Lexique Veritas (Maqasid al-Huruf)

ح ر د

Fonction logique : FRICTION_CYCLE_VECTOR // TARGET_RESTRICTION

Équation des lettres : H. (Friction/Limite) + R (Cycle) + D (Vecteur_Fixe) = Cycle de friction focalisé sur un axe fixe.

Description

Cycle de friction dirigé vers un vecteur spécifique pour restreindre ou isoler un mouvement.
