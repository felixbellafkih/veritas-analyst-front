Racine SH-W-Y (ش و ي) — Lexique Veritas (Maqasid al-Huruf)

ش و ي

Fonction logique : THERMAL_SCORCH // ACTIVE_BURN

Équation des lettres : SH (Dispersion) + W (Lien) + Y (Action_Active) = Lien d'action thermique dispersif.

Description

Lien dispersif d'action active appliquant une chaleur destructive sur l'interface (Griller/Rôtir).
