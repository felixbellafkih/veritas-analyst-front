Racine D.-Y-R (ض ي ر) — Lexique Veritas (Maqasid al-Huruf)

ض ي ر

Fonction logique : MASS_ACTIVE_CYCLE // ACTIVATED_MASS_CYCLE

Équation des lettres : D. (Pression/Masse) + Y (Action_Active) + R (Cycle) = Pression/masse activant un cycle.

Description

Pression/masse activée en cycle. La pression/masse (D.) active (Y) un cycle (R) — pression mise en circulation cyclique.
