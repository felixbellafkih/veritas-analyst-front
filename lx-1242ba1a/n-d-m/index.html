Racine N-D-M (ن د م) — Lexique Veritas (Maqasid al-Huruf)

ن د م

Fonction logique : REVERT_FAILURE // ACTION_REGRET

Équation des lettres : N (Manifestation) + D (Vecteur_Fixe) + M (Matrice) = Manifestation fixée en matrice constatant un échec.

Description

Matrice vectorielle manifestant l'échec irrécupérable d'une action entraînant un flag d'erreur système.

Mots du Coran issus de cette racine

MotTypeDéfinition
نَادِمِينADJECTIVE_PLURALInstances flaggées en échec suite à l'impossibilité d'effectuer un Rollback.
