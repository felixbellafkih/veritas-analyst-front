Racine KH-T-R (خ ت ر) — Lexique Veritas (Maqasid al-Huruf)

خ ت ر

Fonction logique : EXTRACTION_WAY_CYCLE // PROTOCOL_DEFECTION

Équation des lettres : KH (Extraction) + T (Voie) + R (Cycle) = Rupture d'un cycle sur sa voie d'exécution.

Description

Extraction d'une voie cyclique rompant le lien de confiance au milieu de l'exécution (Trahison).
