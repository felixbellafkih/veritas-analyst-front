Racine A-L-T (أ ل ت) — Lexique Veritas (Maqasid al-Huruf)

أ ل ت

Fonction logique : INSTANCE_ALLOC_WAY // ROUTED_ALLOCATION

Équation des lettres : A (Instanciation) + L (Allocation) + T (Voie) = Instanciation d'une allocation acheminée par une voie.

Description

Allocation instanciée sur une voie. L'instanciation (A) alloue (L) une voie (T) — allocation posée sur un trajet.
