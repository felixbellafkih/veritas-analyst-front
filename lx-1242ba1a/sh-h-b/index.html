Racine SH-H-B (ش ه ب) — Lexique Veritas (Maqasid al-Huruf)

ش ه ب

Fonction logique : INTRUSION_COUNTERMEASURE // ENERGY_PULSE

Équation des lettres : SH (Dispersion) + H (Énergie) + B (Base) = L'énergie de la base expulsée violemment sous forme de pulse pour purger le système (INTRUSION_COUNTERMEASURE).

Description

Décharge énergétique active visant à neutraliser un processus tentant d'infiltrer les couches Root (Météore/Flamme).
