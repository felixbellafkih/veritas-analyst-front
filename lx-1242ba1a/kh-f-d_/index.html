Racine KH-F-D. (خ ف ض) — Lexique Veritas (Maqasid al-Huruf)

خ ف ض

Fonction logique : PRESSURE_REDUCTION // DOWNWARD_MODULATION

Équation des lettres : KH (Extraction) + F (Ouverture) + D. (Masse) = Extraction par ouverture réduisant la pression.

Description

Réduction de pression. Extraction (KH) d'une ouverture (F) sous compression (D.) — abaissement du niveau d'intensité.

Paire binaire : R-F-A.
