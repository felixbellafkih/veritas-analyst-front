Racine H.-L-K (ح ل ك) — Lexique Veritas (Maqasid al-Huruf)

ح ل ك

Fonction logique : ABSOLUTE_OBSCURITY // ZERO_LUMINOSITY

Équation des lettres : H. (Limite) + L (Allocation) + K (Enfermement) = Enfermement total de l'allocation lumineuse.

Description

Niveau d'opacité maximal où aucune émission lumineuse n'est allouée (Noir total/Ténèbres intenses).

Paire binaire : N-W-R

Mots du Coran issus de cette racine

MotTypeDéfinition
حَالِكADJECTIVEÉtat Bare Metal totalement dépourvu de rendu visuel (Zero display).
