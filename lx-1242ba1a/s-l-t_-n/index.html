Racine S-L-T.-N (س ل ط ن) — Lexique Veritas (Maqasid al-Huruf)

س ل ط ن

Fonction logique : FLUX_ALLOC_SURFACE_MANIFEST // DELEGATED_AUTHORITY

Équation des lettres : S (Flux) + L (Allocation) + T. (Surface) + N (Manifestation) = Flux allouant une surface manifeste — autorité projetée et visible.

Description

Autorité déléguée par manifestation surfacique. Le flux (S) alloue (L) une surface (T.) qui se manifeste (N) — un pouvoir qui se projette visiblement sur un territoire. Désigne toute forme d'autorité concrète, de preuve tangible ou de juridiction matériellement exercée.
