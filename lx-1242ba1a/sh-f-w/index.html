Racine SH-F-W (ش ف و) — Lexique Veritas (Maqasid al-Huruf)

ش ف و

Fonction logique : DISPERSE_OPEN_LINK // LINKED_OPEN_DISPERSION

Équation des lettres : SH (Dispersion) + F (Ouverture) + W (Lien) = Dispersion ouverte maintenue par un lien.

Description

Dispersion ouverte sur un lien. La dispersion (SH) s'ouvre (F) sur un lien (W) — dispersion ouverte maintenue par un lien.
