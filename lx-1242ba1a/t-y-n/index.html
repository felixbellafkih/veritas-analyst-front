Racine T-Y-N (ت ي ن) — Lexique Veritas (Maqasid al-Huruf)

ت ي ن

Fonction logique : WAY_ACTIVE_MANIFEST // MANIFESTED_WAY

Équation des lettres : T (Voie) + Y (Action_Active) + N (Manifestation) = Voie activant une manifestation.

Description

Voie activée en manifestation. La voie (T) active (Y) une manifestation (N) — voie qui débouche sur une manifestation.
