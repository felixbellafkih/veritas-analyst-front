Racine H-A-R-W-N (ه ا ر و ن) — Lexique Veritas (Maqasid al-Huruf)

ه ا ر و ن

Fonction logique : ENERGY_INSTANCE_CYCLE_LINK_MANIFEST // ENERGIZED_CYCLIC_MANIFEST

Équation des lettres : H (Énergie) + A (Instanciation) + R (Cycle) + W (Lien) + N (Manifestation)

Description

Nom propre coranique (هارون). H (Énergie) + A (Instanciation) + R (Cycle) + W (Lien) + N (Manifestation) = Énergie instanciée en cycle lié et manifesté.
