Racine J-W-F (ج و ف) — Lexique Veritas (Maqasid al-Huruf)

ج و ف

Fonction logique : EMPTY_REGISTER // HOLLOW_NODE

Équation des lettres : J (Assemblage) + W (Lien) + F (Ouverture/Vide) = Un assemblage dont le lien aboutit sur un espace intérieur vide (EMPTY_REGISTER).

Description

Zone de mémoire interne vide et non allouée. Espace creux au centre de l'instance.

Paire binaire : S.-M-D
