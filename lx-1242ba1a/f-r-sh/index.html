ف ر ش

Fonction logique : GRID_DEPLOYMENT // SPREAD

Équation des lettres : F (Ouverture) + R (Cycle) + SH (Dispersion) = Ouverture d'un cycle se dispersant et s'étalant horizontalement sur la matrice (GRID_DEPLOYMENT).

Description

Déploiement horizontal d'une interface ou d'une structure sur une couche de stockage physique.
