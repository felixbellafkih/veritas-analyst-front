Racine Q-D-D (ق د د) — Lexique Veritas (Maqasid al-Huruf)

ق د د

Fonction logique : DOUBLE_VECTOR_PRESSURE // LONGITUDINAL_TEAR

Équation des lettres : Q (Pression) + D (Vecteur) + D (Vecteur) = Pression de séparation sur l'axe vectoriel.

Description

Double pression vectorielle s'exerçant sur une structure, provoquant une déchirure sur sa longueur (Déchirer/Couper en long).
