Racine H.-N-J-R (ح ن ج ر) — Lexique Veritas (Maqasid al-Huruf)

ح ن ج ر

Fonction logique : TRANSIT_CONDUIT // NARROW_PASSAGE

Équation des lettres : H. (Friction) + N (Manifestation) + J (Assemblage) + R (Cycle) = Friction manifestant un assemblage cyclique en passage étroit.

Description

Conduit de transit étroit. La friction (H.) manifeste (N) un assemblage (J) cyclique (R) — canal de passage sous pression.
