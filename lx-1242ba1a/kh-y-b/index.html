Racine KH-Y-B (خ ي ب) — Lexique Veritas (Maqasid al-Huruf)

خ ي ب

Fonction logique : OUTPUT_FAILURE // NULL_RETURN

Équation des lettres : KH (Extraction) + Y (Action_Active) + B (Base) = Extraction active ne produisant aucun résultat sur la base cible.

Description

Échec de sortie. L'extraction (KH) d'une action active (Y) vers la base (B) retourne un résultat nul.

Paire binaire : F-W-Z
