Racine H-Y-M (ه ي م) — Lexique Veritas (Maqasid al-Huruf)

ه ي م

Fonction logique : MEMORY_FAMINE_LOOP // ENDLESS_FETCH

Équation des lettres : H (Énergie) + Y (Action) + M (Matrice) = Boucle d'action cherchant la ressource dans la matrice sans l'atteindre.

Description

Boucle d'action cherchant désespérément une ressource sans jamais être satisfaite (Soif inextinguible).

MotTypeDéfinition
