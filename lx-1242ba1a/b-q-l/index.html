Racine B-Q-L (ب ق ل) — Lexique Veritas (Maqasid al-Huruf)

ب ق ل

Fonction logique : SURFACE_YIELD // BASIC_VEGETATION

Équation des lettres : B (Base) + Q (Pression/Maintien) + L (Allocation) = Allocation d'une ressource maintenue à la base/au sol (SURFACE_YIELD).

Description

Végétation herbacée ou production de surface à cycle court (Légumes/Herbes).
