Racine H-M-D (ه م د) — Lexique Veritas (Maqasid al-Huruf)

ه م د

Fonction logique : ZERO_POWER_STATE // EXTINGUISHED_NODE

Équation des lettres : H (Énergie_Instable) + M (Matrice) + D (Vecteur_Fixe/Arrêt) = Arrêt de l'énergie dans la matrice.

Description

Statut d'une instance dont l'énergie a été totalement consommée ou coupée (Inerte/Éteint).
