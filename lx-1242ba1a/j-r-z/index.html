Racine J-R-Z (ج ر ز) — Lexique Veritas (Maqasid al-Huruf)

ج ر ز

Fonction logique : ASSEMBLY_CYCLE_SEPARATION // BARREN_STATE

Équation des lettres : J (Assemblage) + R (Cycle) + Z (Séparation) = Assemblage dont le cycle est séparé de la production.

Description

État stérile. L'assemblage (J) cycle (R) une séparation (Z) — le cycle sépare l'assemblage de sa capacité productive.
