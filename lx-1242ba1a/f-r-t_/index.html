Racine F-R-T. (ف ر ط) — Lexique Veritas (Maqasid al-Huruf)

ف ر ط

Fonction logique : SURFACE_OVERSTEP_CYCLE // ASYNC_EXCESS

Équation des lettres : F (Ouverture) + R (Cycle) + T. (Surface) = Cycle d'ouverture débordant la surface nominale.

Description

Ouverture d'un cycle dépassant la surface allouée, générant un dépassement asynchrone (Excès/Négligence).
