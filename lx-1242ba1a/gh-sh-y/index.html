Racine GH-SH-Y (غ ش ي) — Lexique Veritas (Maqasid al-Huruf)

غ ش ي

Fonction logique : BLIND_OVERLAY // SENSOR_BLACKOUT

Équation des lettres : GH (Couverture) + SH (Dispersion) + Y (Action_Active) = Une action active dispersant un voile opaque et lourd sur l'instance (BLIND_OVERLAY).

Description

Recouvrement total de l'interface par une couche sombre provoquant l'aveuglement ou le crash temporaire (Évanouissement).
