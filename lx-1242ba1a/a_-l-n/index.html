Racine A.-L-N (ع ل ن) — Lexique Veritas (Maqasid al-Huruf)

ع ل ن

Fonction logique : PUBLIC_EXPOSURE // UNENCRYPTED_BROADCAST

Équation des lettres : A. (Connexion) + L (Allocation) + N (Manifestation) = Une allocation manifestée de manière visible sur la connexion (PUBLIC_EXPOSURE).

Description

Exposition volontaire d'une donnée sur l'interface publique, la rendant lisible par tous les nœuds du réseau sans clé de déchiffrement.

Paire binaire : S-R-R
