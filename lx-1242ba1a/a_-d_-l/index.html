Racine A.-D.-L (ع ض ل) — Lexique Veritas (Maqasid al-Huruf)

ع ض ل

Fonction logique : ACCESS_OBSTRUCTION // BLOCKING_PROTOCOL

Équation des lettres : A. (Connexion) + D. (Masse) + L (Allocation) = Connexion compressée bloquant l'allocation.

Description

Protocole de blocage d'accès. Connexion (A.) compressée (D.) puis allouée (L) — empêchement d'accès à une ressource.
