Racine KH-R-W (خ ر و) — Lexique Veritas (Maqasid al-Huruf)

خ ر و

Fonction logique : EXTRACTION_CYCLE_LINK // SIGNAL_LEAK

Équation des lettres : KH (Extraction/Vide) + R (Cycle) + W (Lien) = Lien d'extraction cyclique.

Description

Extraction d'un cycle via un lien provoquant une fuite ou un dégagement hors de la matrice.
