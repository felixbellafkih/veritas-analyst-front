Racine W-S.-F (و ص ف) — Lexique Veritas (Maqasid al-Huruf)

و ص ف

Fonction logique : LINK_FOCAL_OPEN // ATTRIBUTED_DESCRIPTION

Équation des lettres : W (Lien) + S. (Focale) + F (Ouverture) = Lien focalisant une ouverture d'attribution.

Description

Description par attribution focale. Le lien (W) focalise (S.) une ouverture (F) — projection d'un attribut focalisé sur une cible par ouverture du lien.
