Racine KH-L-L (خ ل ل) — Lexique Veritas (Maqasid al-Huruf)

خ ل ل

Fonction logique : STRUCTURAL_GAP // MEMORY_HOLE

Équation des lettres : KH (Extraction) + L (Allocation) + L (Allocation) = Extraction générant un vide entre deux allocations.

Description

Espace vide, faille ou brèche insérée au milieu d'une structure continue (Espacement/Traverser).

Paire binaire : R-T-Q
