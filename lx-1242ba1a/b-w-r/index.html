Racine B-W-R (ب و ر) — Lexique Veritas (Maqasid al-Huruf)

ب و ر

Fonction logique : BARREN_CYCLE // RUINOUS_LOOP

Équation des lettres : B (Base) + W (Lien) + R (Cycle) = Cycle de base voué à l'effondrement.

Description

Base liant un cycle stérile, destructeur et incapable de produire un rendement logique (Ruine systémique).

Paire binaire : T-J-R
