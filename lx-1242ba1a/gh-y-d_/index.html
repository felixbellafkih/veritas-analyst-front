Racine GH-Y-D. (غ ي ض) — Lexique Veritas (Maqasid al-Huruf)

غ ي ض

Fonction logique : DEEP_ABSORPTION // MEMORY_SINK

Équation des lettres : GH (Couverture) + Y (Action_Active) + D. (Masse) = L'action d'une masse de pression absorbant et couvrant totalement le flux (DEEP_ABSORPTION).

Description

Absorption de flux ou de ressources par les couches profondes de la base de données (Absorption/Baisse).

Paire binaire : F-Y-D.
