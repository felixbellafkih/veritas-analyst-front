Racine H.-D.-D. (ح ض ض) — Lexique Veritas (Maqasid al-Huruf)

ح ض ض

Fonction logique : FRICTION_MASS_MASS // DOUBLE_PRESSURE_FRICTION

Équation des lettres : H. (Friction/Limite) + D. (Pression/Masse) + D. (Pression/Masse) = Friction exerçant une pression/masse redoublée.

Description

Friction sous double pression/masse. La friction (H.) exerce une pression/masse (D.) redoublée (D.) — friction qui presse doublement.
