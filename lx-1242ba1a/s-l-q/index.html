Racine S-L-Q (س ل ق) — Lexique Veritas (Maqasid al-Huruf)

س ل ق

Fonction logique : ABRASIVE_OVERRIDE // VERBAL_LASH

Équation des lettres : S (Flux) + L (Allocation) + Q (Pression_Abrasive) = Allocation d'un flux exerçant une pression tranchante.

Description

Application d'une pression abrasive ou d'un flux de requêtes verbales/logiques agressives pour écraser la cible.
