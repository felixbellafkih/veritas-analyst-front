Racine S-H.-T (س ح ت) — Lexique Veritas (Maqasid al-Huruf)

س ح ت

Fonction logique : ILLICIT_ACQUISITION // CORRUPTED_INTAKE

Équation des lettres : S (Flux) + H. (Friction) + T (Voie) = Flux frictionnant la voie d'acquisition.

Description

Acquisition corrompue. Le flux (S) frictionne (H.) la voie (T) — capture de ressources par un canal illégitime.
