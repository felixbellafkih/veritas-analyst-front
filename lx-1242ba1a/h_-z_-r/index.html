Racine H.-Z.-R (ح ظ ر) — Lexique Veritas (Maqasid al-Huruf)

ح ظ ر

Fonction logique : FRICTION_MASS_CYCLE // ACCESS_RESTRICTION

Équation des lettres : H. (Friction) + Z. (Ombre/Masse_Lourde) + R (Cycle) = Friction massique cyclique bloquant l'accès.

Description

Restriction d'accès. La friction (H.) applique une masse (Z.) cyclique (R) — blocage du passage par pression massique répétée.

Paire binaire : A-DH-N
