Racine S.-A.-Q (ص ع ق) — Lexique Veritas (Maqasid al-Huruf)

ص ع ق

Fonction logique : SYSTEM_SHOCK_OVERRIDE // FATAL_STRIKE

Équation des lettres : S. (Focale) + A. (Connexion) + Q (Pression/Impact) = Focale connectant un impact surpuissant foudroyant le nœud cible (CAPACITY_OVERLOAD).

Description

Décharge énergétique foudroyante provoquant le crash immédiat ou la paralysie d'un processus par surcharge (Foudre/Choc fatal).
