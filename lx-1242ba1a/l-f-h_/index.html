Racine L-F-H. (ل ف ح) — Lexique Veritas (Maqasid al-Huruf)

ل ف ح

Fonction logique : THERMAL_EXPOSURE // SURFACE_SCORCH

Équation des lettres : L (Allocation) + F (Ouverture) + H. (Friction/Chaleur) = Allocation ouvrant la surface à une chaleur de friction.

Description

Exposition d'une surface à une onde thermique détruisant la couche externe (Brûlure de l'interface).
