Racine H-Z-Z (ه ز ز) — Lexique Veritas (Maqasid al-Huruf)

ه ز ز

Fonction logique : ENERGY_DOUBLE_SEPARATION // SEPARATING_ENERGY

Équation des lettres : H (Énergie) + Z (Séparation) + Z (Séparation) = Énergie opérant une séparation répétée.

Description

Énergie à double séparation. L'énergie (H) sépare (Z) puis sépare de nouveau (Z) — énergie qui détache par séparations répétées.
