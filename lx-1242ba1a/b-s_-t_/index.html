Racine B-S.-T. (ب ص ط) — Lexique Veritas (Maqasid al-Huruf)

ب ص ط

Fonction logique : BASE_FOCAL_SURFACE // EXTENDED_SPREAD

Équation des lettres : B (Base) + S. (Focale) + T. (Surface) = Base focalisée s'étendant sur une surface.

Description

Extension focale sur une surface. La base (B) focalise (S.) une surface (T.) — déploiement d'une base sur une surface étendue. Désigne tout étalement, extension, ouverture large ou déploiement de ressources.

Paire binaire : Q-B-D.
