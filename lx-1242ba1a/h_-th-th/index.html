Racine H.-TH-TH (ح ث ث) — Lexique Veritas (Maqasid al-Huruf)

ح ث ث

Fonction logique : FRICTION_DENSITY_DENSITY // ACCELERATION

Équation des lettres : H. (Friction) + TH (Densité) + TH (Densité) = Excitation d'un cluster par friction répétée.

Description

Double application de friction sur une densité provoquant une accélération ou une excitation du flux (Incitation).
