Racine N-W-A (ن و أ) — Lexique Veritas (Maqasid al-Huruf)

ن و أ

Fonction logique : CRITICAL_WEIGHT // SINKING_LOAD

Équation des lettres : N (Manifestation) + W (Lien) + A (Instanciation) = Manifestation d'un lien lourd sur la source.

Description

Charge matérielle affaissant la structure sous l'effet de son propre poids (Peser lourdement).
