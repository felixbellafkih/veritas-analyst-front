Racine GH-Y-R (غ ي ر) — Lexique Veritas (Maqasid al-Huruf)

غ ي ر

Fonction logique : STATE_MUTATION // VARIABLE_OVERRIDE

Équation des lettres : GH (Couverture/Altération) + Y (Action_Active) + R (Cycle) = L'action active altérant le cycle pour remplacer sa valeur d'origine par une autre (STATE_MUTATION).

Description

Instruction de modification d'un état, d'une valeur ou d'une constante (Autre/Changer).
