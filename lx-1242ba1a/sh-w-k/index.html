Racine SH-W-K (ش و ك) — Lexique Veritas (Maqasid al-Huruf)

ش و ك

Fonction logique : POWER_SPIKE // THRESHOLD_IMPACT

Équation des lettres : SH (Dispersion) + W (Lien) + K (Enfermement/Point) = Le lien enfermé dans un point acéré concentrant la force de dispersion (POWER_SPIKE).

Description

Pic d'intensité électrique ou force de masse d'une instance lors d'une collision logique (Épine/Puissance armée).
