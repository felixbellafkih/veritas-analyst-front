Racine S.-R-S.-R (ص ر ص ر) — Lexique Veritas (Maqasid al-Huruf)

ص ر ص ر

Fonction logique : RESONANCE_AMPLIFIED // CYCLICAL_COMPRESSION_WAVE

Équation des lettres : S. (Focale) + R (Cycle) + S. (Focale) + R (Cycle) = Double cycle focalisé en amplification progressive.

Description

Onde de compression cyclique amplifiée. La focale (S.) cycle (R) puis refocalise (S.) et recycle (R) — intensification progressive.
