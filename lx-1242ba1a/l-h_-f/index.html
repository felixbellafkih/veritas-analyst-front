Racine L-H.-F (ل ح ف) — Lexique Veritas (Maqasid al-Huruf)

ل ح ف

Fonction logique : ALLOC_FRICTION_OPEN // FRICTION_OPENED_ALLOCATION

Équation des lettres : L (Allocation) + H. (Friction/Limite) + F (Ouverture) = Allocation obtenue par friction jusqu'à l'ouverture.

Description

Allocation sous friction ouverte. L'allocation (L) passe par une friction (H.) qui s'ouvre (F) — allocation soumise à une friction jusqu'à l'ouverture.
