Racine KH-N-Q (خ ن ق) — Lexique Veritas (Maqasid al-Huruf)

خ ن ق

Fonction logique : THROTTLE_CHOKE // BANDWIDTH_STRANGULATION

Équation des lettres : KH (Extraction/Vide) + N (Manifestation) + Q (Pression) = Pression coupant la manifestation du flux.

Description

Restriction violente du canal d'alimentation provoquant l'étouffement du nœud (Étranglement).

Paire binaire : T-N-F-S

Mots du Coran issus de cette racine

MotTypeDéfinition
مُنْخَنِقَةADJECTIVEInstance détruite par étranglement de sa bande passante.

Présente dans 1 verset(s) du Coran

5:3
