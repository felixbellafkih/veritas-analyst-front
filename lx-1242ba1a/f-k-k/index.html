Racine F-K-K (ف ك) — Lexique Veritas (Maqasid al-Huruf)

ف ك

Fonction logique : PROCESS_DETACH // UNLOCK_ROUTINE

Équation des lettres : F (Ouverture) + K (Capture/Verrou) + K (Capture/Verrou) = L'ouverture et le retrait successif des verrous de capture pour isoler l'instance (PROCESS_DETACH).

Description

Dissociation d'éléments liés. Libération d'un processus esclave (Unbind/Unlock).

Paire binaire : R-B-T.
