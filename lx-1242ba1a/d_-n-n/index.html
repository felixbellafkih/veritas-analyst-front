Racine D.-N-N (ض ن ن) — Lexique Veritas (Maqasid al-Huruf)

ض ن ن

Fonction logique : DOUBLE_MANIFESTATION_HOLD // RESOURCE_AVARICE

Équation des lettres : D. (Masse) + N (Manifestation) + N (Manifestation) = Verrouillage massif de la manifestation.

Description

Rétention massive d'une double manifestation, empêchant l'allocation de la donnée au réseau (Rétention/Avarice).
