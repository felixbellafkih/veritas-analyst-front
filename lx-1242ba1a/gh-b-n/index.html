Racine GH-B-N (غ ب ن) — Lexique Veritas (Maqasid al-Huruf)

غ ب ن

Fonction logique : OPAQUE_BASE_MANIFEST // HIDDEN_DEFICIT

Équation des lettres : GH (Opacité) + B (Base) + N (Manifestation) = Opacité de la base se manifestant en déficit.

Description

Déficit opaque. L'opacité (GH) de la base (B) se manifeste (N) — perte cachée qui finit par se manifester.

Paire binaire : R-B-H.
