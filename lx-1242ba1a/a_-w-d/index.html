Racine A.-W-D (ع و د) — Lexique Veritas (Maqasid al-Huruf)

ع و د

Fonction logique : PROCESS_LOOP // RETURN_STATE

Équation des lettres : A. (Connexion_Profonde) + W (Lien/Continuité) + D (Vecteur_Dirigé) = La connexion continue dirigeant le vecteur vers son point de départ (PROCESS_LOOP).

Description

Instruction de retour au début de la boucle ou répétition d'un cycle déjà exécuté.

Paire binaire : B-D-A.
