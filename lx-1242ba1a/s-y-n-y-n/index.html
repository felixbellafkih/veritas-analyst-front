Racine S-Y-N-Y-N (س ي ن ي ن) — Lexique Veritas (Maqasid al-Huruf)

س ي ن ي ن

Fonction logique : FLUX_ACTIVE_MANIFEST_ACTIVE_MANIFEST // DOUBLE_ACTIVE_MANIFEST_FLUX

Équation des lettres : S (Flux) + Y (Action_Active) + N (Manifestation) + Y (Action_Active) + N (Manifestation)

Description

Nom propre coranique (سينين). S (Flux) + Y (Action_Active) + N (Manifestation) + Y (Action_Active) + N (Manifestation) = Flux activé en manifestation, réactivé en manifestation.

Présente dans 1 verset(s) du Coran

95:2

Lexique Veritas : chaque racine est décodée par la charge physique de ses lettres (Maqasid al-Huruf), sans recours aux dictionnaires historiques ni aux exégèses traditionnelles.
