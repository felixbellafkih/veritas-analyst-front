Racine B-Y-D (ب ي د) — Lexique Veritas (Maqasid al-Huruf)

ب ي د

Fonction logique : BASE_ACTIVE_VECTOR // VECTORED_BASE

Équation des lettres : B (Base) + Y (Action_Active) + D (Vecteur_Fixe) = Base activée vers un vecteur fixe.

Description

Base activée vers un vecteur fixe. La base (B) active (Y) un vecteur fixe (D) — base conduite jusqu'à un point fixe.
