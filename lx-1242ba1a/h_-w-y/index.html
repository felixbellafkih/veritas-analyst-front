Racine H.-W-Y (ح و ي) — Lexique Veritas (Maqasid al-Huruf)

ح و ي

Fonction logique : FRICTION_LINK_ACTIVE // ENCAPSULATION

Équation des lettres : H. (Friction/Enceinte) + W (Lien) + Y (Action_Active) = Action de lier une enceinte autour d'une cible.

Description

Action active de lier une friction pour contenir ou englober une charge (Contenance).
