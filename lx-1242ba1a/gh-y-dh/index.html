Racine GH-Y-DH (غ ي ظ) — Lexique Veritas (Maqasid al-Huruf)

غ ي ظ

Fonction logique : ACTIVE_SEPARATION_FURY // THERMAL_ANGER

Équation des lettres : GH (Opacité) + Y (Action_Active) + DH (Séparation/Émission) = Émission brûlante masquée.

Description

Action active provoquant une séparation due à une concentration d'énergie thermique opaque (Colère foudroyante/Rage).
