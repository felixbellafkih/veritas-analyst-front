Racine N-W-L (ن و ل) — Lexique Veritas (Maqasid al-Huruf)

ن و ل

Fonction logique : RESOURCE_GRANT // ACCESS_PROVISION

Équation des lettres : N (Manifestation) + W (Lien) + L (Allocation) = Manifestation d'un lien d'allocation vers la cible.

Description

Octroi d'accès à une ressource ou remise d'un privilège matériel (Don/Accorder).

Paire binaire : M-N-A.
