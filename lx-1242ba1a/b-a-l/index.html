Racine B-A-L (ب ا ل) — Lexique Veritas (Maqasid al-Huruf)

ب ا ل

Fonction logique : BASE_INSTANCE_ALLOC // INTERNAL_STATE

Équation des lettres : B (Base) + A (Instanciation) + L (Allocation) = Base instanciant une allocation interne.

Description

État interne. La base (B) instancie (A) une allocation (L) — condition interne allouée à la base.
