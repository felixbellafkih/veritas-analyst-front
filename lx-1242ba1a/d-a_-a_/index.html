Racine D-A.-A. (د ع ع) — Lexique Veritas (Maqasid al-Huruf)

د ع ع

Fonction logique : FIXED_CONNEXION_CONNEXION // REPETITIVE_REPULSION

Équation des lettres : D (Impulsion) + A. (Connexion) + A. (Connexion) = Double percussion de connexion repoussante.

Description

Double impulsion de connexion fixe visant à repousser brutalement une instance (Éviction répétée).
