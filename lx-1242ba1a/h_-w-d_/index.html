Racine H.-W-D. (ح و ض) — Lexique Veritas (Maqasid al-Huruf)

ح و ض

Fonction logique : DATA_BASIN // POOLED_BUFFER

Équation des lettres : H. (Enceinte) + W (Lien) + D. (Masse) = Masse fluide contenue dans un lien d'enceinte.

Description

Masse de données ou de fluide liée dans une enceinte matérielle d'accueil (Bassin).
