Racine N-H.-B (ن ح ب) — Lexique Veritas (Maqasid al-Huruf)

ن ح ب

Fonction logique : MANIFEST_FRICTION_BASE // BASE_LIMITED_MANIFESTATION

Équation des lettres : N (Manifestation) + H. (Friction/Limite) + B (Base) = Manifestation atteignant la limite de sa base.

Description

Manifestation limitée sur une base. La manifestation (N) rencontre sa limite (H.) sur une base (B) — manifestation portée jusqu'à la limite de sa base.
