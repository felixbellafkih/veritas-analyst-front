Racine L-W-Y (ل و ي) — Lexique Veritas (Maqasid al-Huruf)

ل و ي

Fonction logique : VECTOR_TWIST // LOGIC_BENDING

Équation des lettres : L (Allocation) + W (Lien) + Y (Action_Active/Torsion) = Allocation d'un lien actif déformé.

Description
