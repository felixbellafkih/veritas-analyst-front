Racine Q-Y-D. (ق ي ض) — Lexique Veritas (Maqasid al-Huruf)

ق ي ض

Fonction logique : PRESSURE_ACTIVE_MASS // IMPOSED_ASSIGNMENT

Équation des lettres : Q (Pression) + Y (Action_Active) + D. (Masse) = Pression active imposant une masse.

Description

Assignation imposée. La pression (Q) active (Y) une masse (D.) — force active imposant une masse sur la cible.
