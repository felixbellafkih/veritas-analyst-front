Racine H.-N-K (ح ن ك) — Lexique Veritas (Maqasid al-Huruf)

ح ن ك

Fonction logique : OVERRIDE_CONTROL // ROOT_SUBJUGATION

Équation des lettres : H. (Friction) + N (Manifestation) + K (Capture) = Capture de la manifestation la forçant à se soumettre à la friction.

Description

Capture de la manifestation pour la soumettre intégralement via une friction directive (Maîtriser/Mettre le mors).
