Racine S-B-GH (س ب غ) — Lexique Veritas (Maqasid al-Huruf)

س ب غ

Fonction logique : FLUX_BASE_OPAQUE // TOTAL_IMMERSION

Équation des lettres : S (Flux) + B (Base) + GH (Opacité) = Flux couvrant la base d'opacité totale.

Description

Immersion totale. Le flux (S) couvre la base (B) d'opacité (GH) — saturation complète de la base par un flux opaque.
