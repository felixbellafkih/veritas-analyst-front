Racine K-F-T (ك ف ت) — Lexique Veritas (Maqasid al-Huruf)

ك ف ت

Fonction logique : CAPTURE_OPEN_WAY // OPEN_WAY_ENCLOSURE

Équation des lettres : K (Enfermement) + F (Ouverture) + T (Voie) = Enfermement ouvert sur une voie.

Description

Enfermement ouvert sur une voie. L'enfermement (K) s'ouvre (F) sur une voie (T) — enfermement qui reçoit par une voie ouverte.
