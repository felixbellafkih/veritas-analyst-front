Racine R-F-R-F (ر ف ر ف) — Lexique Veritas (Maqasid al-Huruf)

ر ف ر ف

Fonction logique : CYCLE_OPEN_CYCLE_OPEN // LAYERED_SPREAD

Équation des lettres : R (Cycle) + F (Ouverture) + R (Cycle) + F (Ouverture) = Double cycle d'ouverture déployant des couches.

Description

Étalage en couches. Le cycle (R) ouvre (F) puis recycle (R) et rouvre (F) — déploiement en couches successives par cycle d'ouverture répété.

MotTypeDéfinition
