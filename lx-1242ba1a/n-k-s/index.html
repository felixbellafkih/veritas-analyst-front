Racine N-K-S (ن ك س) — Lexique Veritas (Maqasid al-Huruf)

ن ك س

Fonction logique : INVERTED_STATE // REVERSE_ORIENTATION

Équation des lettres : N (Manifestation) + K (Enfermement) + S (Flux) = Manifestation d'un enfermement inversant le flux.

Description

Renversement complet de la structure ou du pointeur d'une instance (Tête en bas/Inversion).
