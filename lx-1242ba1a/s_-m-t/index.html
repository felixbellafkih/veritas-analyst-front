Racine S.-M-T (ص م ت) — Lexique Veritas (Maqasid al-Huruf)

ص م ت

Fonction logique : MUTE_STATE // NO_OUTPUT

Équation des lettres : S. (Focale) + M (Matrice) + T (Voie/Connexion) = La voie de connexion de la matrice figée dans un alignement silencieux (MUTE_STATE).

Description

Silence complet du port de sortie. Aucun paquet d'information envoyé sur l'interface (Silence/Inactivité vocale).

Paire binaire : F-W-H
