Racine N-W-SH (ن و ش) — Lexique Veritas (Maqasid al-Huruf)

ن و ش

Fonction logique : MANIFEST_LINK_DISPERSE // REACH_ATTEMPT

Équation des lettres : N (Manifestation) + W (Lien) + SH (Dispersion) = Manifestation tentant de lier un élément dispersé.

Description

Tentative de portée. La manifestation (N) lie (W) une dispersion (SH) — le point de manifestation tente de se lier à un élément dispersé.
