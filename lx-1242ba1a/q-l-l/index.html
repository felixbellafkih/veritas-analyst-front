Racine Q-L-L (ق ل) — Lexique Veritas (Maqasid al-Huruf)

ق ل

Fonction logique : MINIMAL_ALLOCATION // LOW_CAPACITY

Équation des lettres : Q (Pression) + L (Allocation) + L (Allocation) = La pression d'une double allocation extrêmement restreinte (MINIMAL_ALLOCATION).

Description

Quantité de données ou de ressources insuffisante pour déclencher un processus critique (Peu/Minime).

Paire binaire : K-TH-R
