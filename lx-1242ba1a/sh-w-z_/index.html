Racine SH-W-Z. (ش و ظ) — Lexique Veritas (Maqasid al-Huruf)

ش و ظ

Fonction logique : DISPERSE_LINK_MASS // RADIATING_HEAT

Équation des lettres : SH (Dispersion) + W (Lien) + Z. (Ombre/Masse_Lourde) = Dispersion liée à une masse irradiante.

Description

Chaleur irradiante. La dispersion (SH) lie (W) une masse (Z.) — masse liée émettant une dispersion intense.
