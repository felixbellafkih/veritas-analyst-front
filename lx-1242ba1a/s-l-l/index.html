Racine S-L-L (س ل ل) — Lexique Veritas (Maqasid al-Huruf)

س ل ل

Fonction logique : LINEAR_EXTRACTION // THREAD_DERIVATION

Équation des lettres : S (Flux) + L (Allocation) + L (Allocation_Dérivée) = Flux allouant une dérivation linéaire.

Description

Extraction délicate et linéaire d'un thread ou d'une instance dérivée à partir de la matrice d'origine.
