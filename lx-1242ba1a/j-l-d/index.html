Racine J-L-D (ج ل د) — Lexique Veritas (Maqasid al-Huruf)

ج ل د

Fonction logique : ASSEMBLY_ALLOC_VECTOR // SURFACE_IMPACT

Équation des lettres : J (Assemblage) + L (Allocation) + D (Vecteur_Fixe) = Assemblage allouant un impact sur un vecteur fixe (l'enveloppe).

Description

Impact assemblé sur un vecteur fixe. L'assemblage (J) alloue (L) un vecteur fixe (D) — application d'une force assemblée dirigée vers une surface fixe. Le lien étymologique avec جِلْد (peau/enveloppe) confirme que le vecteur fixe cible est l'enveloppe extérieure.
