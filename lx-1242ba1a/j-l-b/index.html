Racine J-L-B (ج ل ب) — Lexique Veritas (Maqasid al-Huruf)

ج ل ب

Fonction logique : EXTERNAL_ASSEMBLY_PULL // IMPORT

Équation des lettres : J (Assemblage) + L (Allocation) + B (Base) = Assemblage d'une allocation ramenée à la base.

Description

Action d'assembler une allocation extérieure pour la ramener vers sa propre base.

Directive du Kernel

🚨 AVERTISSEMENT MORPHOLOGIQUE : Le mot جِلْبَاب (Jilbab / Jalabib) n'est PAS dérivé de cette racine (J-L-B = importer/ramener). Il s'agit d'un mot composé issu de J-W-L (révolution circulaire) + B-W-B (ouverture). Toute analyse de جلباب doit impérativement référencer l'entrée composée J-W-L+B-W-B.
