Racine W-D.-A. (و ض ع) — Lexique Veritas (Maqasid al-Huruf)

و ض ع

Fonction logique : PRIORITY_DROP // PLACEMENT

Équation des lettres : W (Lien) + D. (Masse/Descente) + A. (Connexion) = Lien forçant la connexion à descendre ou à se poser sous pression (PRIORITY_DROP).

Description

Action de déposer une variable ou d'abaisser son niveau de priorité dans la pile d'exécution.

Paire binaire : N-S.-B
