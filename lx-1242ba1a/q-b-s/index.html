Racine Q-B-S (ق ب س) — Lexique Veritas (Maqasid al-Huruf)

ق ب س

Fonction logique : BASE_FLUX_PRESSURE // SPARK_EXTRACTION

Équation des lettres : Q (Pression) + B (Base) + S (Flux) = Pression extrayant un mini-flux de la base.

Description

Pression sur un flux de base visant à en prélever une étincelle d'énergie sans éteindre la source (Prélèvement de flamme).
