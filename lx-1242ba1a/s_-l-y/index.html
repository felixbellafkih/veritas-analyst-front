Racine S.-L-Y (ص ل ي) — Lexique Veritas (Maqasid al-Huruf)

ص ل ي

Définition 1

Fonction logique : THERMAL_BURN // EXTREME_HEAT_EXPOSURE

Équation des lettres : S. (Focale) + L (Allocation) + Y (Action_Active/Chaleur) = Action allouant une focale brûlante.

Description

Exposition d'un processus à une zone de haute entropie thermique (Rôtir/Brûler).
