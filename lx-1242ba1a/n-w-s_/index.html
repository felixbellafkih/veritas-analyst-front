Racine N-W-S. (ن و ص) — Lexique Veritas (Maqasid al-Huruf)

ن و ص

Fonction logique : MANIFEST_LINK_FOCAL // ESCAPE_VECTOR

Équation des lettres : N (Manifestation) + W (Lien) + S. (Focale) = Manifestation liée à une focale d'échappement.

Description

Vecteur d'échappement. La manifestation (N) lie (W) une focale (S.) — le point de manifestation se lie à une focale de sortie.

Paire binaire : H.-S.-R
