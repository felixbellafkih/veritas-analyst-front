Racine L-W-DH (ل و ذ) — Lexique Veritas (Maqasid al-Huruf)

ل و ذ

Fonction logique : ALLOC_LINK_EMISSION // EMISSION_LINKED_ALLOCATION

Équation des lettres : L (Allocation) + W (Lien) + DH (Émission) = Allocation liée à une émission.

Description

Allocation liée à une émission. L'allocation (L) se lie (W) à une émission (DH) — allocation rattachée à ce qui émet.
