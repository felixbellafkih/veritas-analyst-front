Racine N-A-Y (ن أ ي) — Lexique Veritas (Maqasid al-Huruf)

ن أ ي

Fonction logique : REMOTE_SEPARATION // DISTANT_DISCONNECT

Équation des lettres : N (Manifestation) + A (Instanciation) + Y (Action_Active) = Manifestation active d'une prise de distance avec la source.

Description

Action d'éloignement ou de déconnexion d'un nœud source vers un secteur distant de l'architecture.
