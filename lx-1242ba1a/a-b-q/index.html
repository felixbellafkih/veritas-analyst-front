Racine A-B-Q (أ ب ق) — Lexique Veritas (Maqasid al-Huruf)

أ ب ق

Fonction logique : BUS_EVICTION // SUDDEN_DISCONNECT

Équation des lettres : A (Instanciation) + B (Base) + Q (Pression/Impact) = Une base subissant un impact forçant l'instanciation d'une sortie non autorisée.

Description

Déconnexion forcée ou éjection d'une unité de sa base suite à une pression ou un conflit de bus. 🚨 SÉCURITÉ KERNEL : Le 'fugitif' (Abaqa) incarne cette fonction par son extraction brutale du système d'autorité, mais la mécanique est celle d'un processus s'éjectant du runtime.
