Racine S.-W-T (ص و ت) — Lexique Veritas (Maqasid al-Huruf)

ص و ت

Définition 1

Fonction logique : AUDIO_SIGNAL // FREQUENCY_OUTPUT

Équation des lettres : S. (Focale) + W (Lien) + T (Voie/Émission) = Focale d'un lien émettant sur une voie audible.

Description

Onde fréquentielle émise par une instance pour communication ou alerte (Voix/Son).
